## Итог (что написали ребятам)

Причина: умер прокси `dlyamasterapoblokirovkam.top`. Ночная правка адреса в Firebase дошла до монолита,
но не дошла до Config Publisher (`proxyconfig.aggone.dev`, на дев-сервере). Publisher хранит свою копию
коллекций, шифрует и выкладывает в S3, откуда часть сборок читает конфиг. Починило обновление в publisher.
Сделано: новый прокси `api2.ragnaros.top` (haproxy → olimpapi.cc); адрес API → api2 в publisher и Firebase
для iOS `com.olimpRF1`, Android `com.olimp.app` и `com.olmp.premium.client`. QA (Ксения, Глеб) подтвердили.

## Пустая главная (витрина) у iOS com.olimpRF1 — отдельная проблема, найдена 31.10 ~13:10

Симптом: «витрины нет, лайв показывается». `GET /api/mobile/main?...&bundle_id=com.olimpRF1` (заголовок
`X-AppVersion: 246.0`) через `velmorathion.com` и напрямую `api.ragnaros.net` отдаёт одинаково:
`viewscreen_name: "Проверка"`, секции только `ident_status` + `matches` (топ-матчи `{"data":[]}`).
Для `X-AppVersion: 247.0` — «Баннеры актуальная витрина com» (promo, 6×links_small, favourite_matches, matches).
Прокси/конфиги ни при чём.

Причина: 29.10 14:01–14:08 UTC в админке 5 раз пересортировали витрины (лог `storage/logs/db_query_log-2026-10-29.log`,
`update viewscreens set sort`). Финал 14:08:16: «Проверка» (id 11) sort 7 > «Баннеры актуальная витрина com» (id 15)
sort 4. «Проверка» привязана к com.olimpRF1 для версий 0–246.0.0 → перекрывает рабочую для всех текущих версий.
В промежуточном состоянии 14:04:25 было: Default(3)=7, Витрина для Леры(17)=6, Баннеры(15)=5, Проверка(11)=4.
Кто сортировал — в `storage/logs/admin/actions-2026-10-29.log` не видно. Кнопка «Опубликовать» ничего не меняет.
Лечение (НЕ сделано, ждали Юлю/Костю — вдруг «Проверка» нужна для ревью App Store): в admin3 → Витрины опустить
«Проверку» ниже «Баннеры…» или отвязать от неё com.olimpRF1. Hash главной сменится — приложение перезапросит main.

Команды диагностики:
```bash
# какие витрины у бандла и их порядок
SELECT v.id,v.name,v.sort,v.segment_id,v.starts_at,v.ends_in,v.updated_at,va.min_app_version,va.max_app_version
FROM viewscreens v JOIN viewscreen_has_applications va ON va.viewscreen_id=v.id JOIN applications a ON a.id=va.application_id
WHERE a.bundle_name='com.olimpRF1' ORDER BY v.sort DESC;
# что реально отдаёт главная по версиям
curl -s "https://api.ragnaros.net/api/mobile/main?is_auth=0&lang_id=0&is_new=0&platforma=IOS1&bundle_id=com.olimpRF1" \
  -H 'X-Platform: COMAPP' -H 'Accept: application/json' -H 'X-AppVersion: 246.0' | jq '{viewscreen_name, s:[.data[].type]}'
# история сортировки
grep -a 'update `viewscreens` set `sort`' storage/logs/db_query_log-<дата>.log   # внутри контейнера app
```
Главная запрашивается один раз при старте (и при смене языка), дальше приложение сравнивает `hash` (`/api/mobile/main/hash`).
