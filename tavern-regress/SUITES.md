# Проверки: что есть, как запускать, чего ждать

## EditMode-тесты (61 штука, ~40 секунд)

Данные, каталог, модели: битые ссылки, ноды дефов, бюджет треугольников,
достижимость раскладок, атрибуты, рецепты.

```
run_tests {"mode":"EditMode"}          # старт, вернёт job_id
get_test_job {"job_id":"…","include_failed_tests":true}
```

⚠️ **В play не стартует.** Ответ «Cannot start a test run while the Editor is in
or entering Play Mode» — не поломка, а занятый редактор: дождаться выхода.
⚠️ Пока Илья в play, Unity ОТКЛАДЫВАЕТ компиляцию: свежие правки в тестах не
участвуют, пока он не выйдет. Проверять `EditorApplication.isCompiling`.

## Живые пробы (в play, секунды)

- `tavern-game/probes/invariants_play.py` — правила, которые видны только в
  движении: спрятанное не наводится, нет переливов, нет невидимых объектов,
  вложенный знает хозяина.
- `tavern-game/probes/level_roundtrip.py` — сохранить, загрузить, сверить мир.
  Ловит тихие потери состояния.
- `tavern-game/probes/node_audit.py` — ноды дефов против моделей.

## Офлайн-компиляция (5 секунд, без Unity)

```
cd /media/ilya/T714/Unity/Tavern-fresh && python3 compile_check.py
```
Скрипт берёт проект из текущей папки (`os.getcwd()`) — запуск откуда-то ещё
молча собирает не то и оставляет мусорный `Temp/compile_check`.
Roslyn по всем сборкам. Быстрее, чем ждать редактор; ошибка чужой сессии в
общем файле видна тут же — в общем дереве это норма, перепроверить через минуту.
