# Проверки: что есть, как запускать, чего ждать

## Брифинг и линт граблей: `bugs.py` (секунда, без Unity)

```
python3 ~/.claude/skills/tavern-regress/probes/bugs.py               # области и счётчики
python3 ~/.claude/skills/tavern-regress/probes/bugs.py наведение     # брифинг по области
python3 ~/.claude/skills/tavern-regress/probes/bugs.py P044          # запись целиком
python3 ~/.claude/skills/tavern-regress/probes/bugs.py --lint        # формат и ссылки
```
Читает `tavern-game/PITFALLS.md` и `INVARIANTS.md`. Линт краснеет на дублях
номеров, неизвестных областях, записях без симптома/причины/правила и на
инвариантах со ссылкой на несуществующую запись; предупреждает о записях без
«Решение» и «Защита».

## EditMode-тесты (61 штука, ~40 секунд)

Данные, каталог, модели: битые ссылки, ноды дефов, бюджет треугольников,
достижимость раскладок, атрибуты, рецепты, составные коллайдеры.

```
run_tests {"mode":"EditMode"}          # старт, вернёт job_id
get_test_job {"job_id":"…","include_failed_tests":true}
```

⚠️ **В play не стартует.** Ответ «Cannot start a test run while the Editor is in
or entering Play Mode» — не поломка, а занятый редактор: дождаться выхода.
⚠️ Пока Илья в play, Unity ОТКЛАДЫВАЕТ компиляцию: свежие правки в тестах не
участвуют, пока он не выйдет. Проверять `EditorApplication.isCompiling`.
⚠️ Илья (01.09) разрешил сессиям самим входить в play и выходить из него —
предупреждать соседей сообщением, у них может идти проба.

## Живые пробы (в play, секунды)

- `probes/invariants_play.py` — правила, которые видны только в
  движении: спрятанное не наводится, нет переливов, нет невидимых объектов,
  вложенный знает хозяина.
- `probes/level_roundtrip.py` — сохранить, загрузить, сверить мир.
  Ловит тихие потери состояния.
- `probes/node_audit.py` — ноды дефов против моделей.
- `probes/transfer_probe.py` — перенос: предмет в руке не исчезает (инвариант 3);
  без `--run` только проверяет привязки, полный прогон — в своём play.
- Протокол замеров и грабли зондов — `probes/README.md`; зонды `hover_probe.cs`,
  `pose_probe.cs`, `corner_pose_probe.cs` — готовые куски для `execute_code`.

## Кисть багов (Илья рисует, сессия читает)

В дебаг-меню (вкладка «Вид») строка с иконкой жука: левая кнопка ставит
точки по поверхностям, правая снимает последнюю, «Стереть отметки» чистит
всё. Отметки уезжают в `BugMarks.json` рядом с проектом вместе с id объекта и
именем узла под точкой. Сессия читает файл напрямую — область бага приходит в
машинном виде (первый случай: провал предметов внутрь угловой тумбы нашёлся
за один замер, P067).

## Офлайн-компиляция (5 секунд, без Unity)

```
python3 compile_check.py
```
Скрипт берёт проект из текущей папки (`os.getcwd()`) — запуск откуда-то ещё
молча собирает не то и оставляет мусорный `Temp/compile_check`.
Roslyn по всем сборкам. Быстрее, чем ждать редактор; ошибка чужой сессии в
общем файле видна тут же — в общем дереве это норма, перепроверить через минуту.
Пачка `CS0006` — две сессии запустили одновременно, повторить (P009).

## Старт сессии, здоровье скилов, pre-commit

```
python3 ~/.claude/skills/tavern-regress/probes/start.py         # мост, play, репозитории, последние решения и грабли, очередь вопросов
python3 ~/.claude/skills/tavern-regress/probes/skills_lint.py   # доменные файлы: размер, оглавление, даты в заголовках, разделы-гиганты
cp tavern-regress/probes/pre-commit.sh .git/hooks/pre-commit    # в репозитории скилов: линт граблей перед каждым коммитом
```

## Один прогон всего

```
python3 ~/.claude/skills/tavern-regress/probes/check_all.py
```
Линт граблей → компиляция → тесты (если редактор свободен) → живые пробы (если
в play). Печатает вердикт и что именно красное.
