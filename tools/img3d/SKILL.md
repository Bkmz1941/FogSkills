# 3D по картинке (img3d)

Модель считается локально на RTX 3060 Ti (8 ГБ). Это **черновик под доводку
в Blender**, а не готовый игровой ассет. Заведено 2026-10-06 (Илья: «давай
попробуем»).

**Годится:** мелкий реквизит на полки и в мусор — бутылки, банки, тюбики,
игрушки, коробки, сумки. **Не годится:** то, с чем игрок взаимодействует
(газета, кружка в руке, мебель со створками) — там нужна точная геометрия и
узлы, это наши параметрические `*_scene.py` (tavern-game/BLENDER.md).

**Корень:** `/media/ilya/T714/img3d` (exFAT, ~24 ГБ). Команда `img3d` в PATH
через `~/.local/bin/img3d` → симлинк на `$ROOT/img3d`.

## Команда

```
img3d картинка_cut.png [-o имя] [--seed 42] [--faces 100000] [--tex 2048] [--steps 12] [--no-preview] [--linear]
```

- Результат — `$ROOT/out/<имя>.glb` (PBR, текстура PNG) и
  `$ROOT/out/<имя>_preview.png` (4 ракурса + вид без текстуры, рендер
  headless Blender 5.2). **Превью смотреть всегда** — модель додумывает
  невидимое.
- Время ~2 мин на модель (из них ~50 с — чтение весов с диска), первый
  прогон после включения — до 4 мин. VRAM до ~5,7 ГБ, RAM пик ~10 ГБ.
- `--faces` — НЕ трогать для игровой сетки: на 5000 форма держится, но рвутся
  края текстуры (этикетка кетчупа). Упрощать в Blender.
- `--linear` — отключить перевод цвета в sRGB (по умолчанию включён: TRELLIS
  пишет base color в линейном пространстве, без перевода модели выходили
  заметно темнее картинки).

## Картинка на вход

Нужен PNG с прозрачным фоном — `*_cut.png` из `ig` (скил image-gen, `--cut`).
Своего удаления фона нет (официальный RMBG-2.0 закрыт).

**Модель превращает в геометрию ВСЁ непрозрачное на картинке:**
- тень под предметом → плоский диск/пластина под моделью (06.10: кетчуп,
  сумка). Порогом альфы не убрать — тень почти непрозрачная. Генерировать
  картинку без тени (`no shadow, no ground` в промпте `ig`) или удалять диск
  в Blender;
- манекен → у худи в 3D появилась серая шея. Для одежды — без манекена или
  удалять лишнее.

Лучше всего работает вид три четверти спереди-сверху (камера image-gen) —
видно форму и две стороны.

## Что модель делает плохо

- **Додумывает невидимые стороны** и иногда ошибается: у худи на спине
  нарисовался такой же карман, как спереди.
- **Чёрное и глянцевое**: на чёрной сумке серая дуга-артефакт, пластик и кожа
  «залоснились».
- **Сетка**: ~95 тыс. треугольников, не замкнутая, UV автоматические
  лоскутами, металл 0, шероховатость 1 (всё матовое).

## Доводка до игры (Blender 5.2)

1. Импорт `.glb`, удалить лишнее (диск тени, шея манекена).
2. Decimate или ретопология до 2–5 тыс. треугольников (бюджет модели в игре —
   тест `ModelBudgetTests`, потолок 15 000).
3. При желании — перезапечь текстуру на чистую развёртку
   (`blender_bake_highpoly_to_lowpoly` нашего моста).
4. Масштаб в метрах, пивот по низу, имя по правилам каталога — дальше обычный
   экспорт FBX по tavern-game/BLENDER.md.

## Устройство

- `$ROOT/.venv` — Python 3.12 (`mkdir -p .venv/lib64 && python3 -m venv
  --copies .venv` — exFAT без симлинков). torch 2.6.0+cu124 скопирован из
  venv voice-translate, xformers вместо flash-attn, transformers 4.57.1
  (5.x ломает DINOv3: нет `.layer`).
- `$ROOT/cuda/` — nvcc 12.4 из redist-архивов NVIDIA, только для сборки
  расширений (системного CUDA toolkit нет).
- Расширения nvdiffrast 0.4.0, CuMesh, FlexGEMM, o-voxel — собраны из
  исходников под sm_86 (колёса ComfyUI-Trellis2 — под sm_120 и torch 2.9, не
  подходят). Исходники и код TRELLIS.2 — `$ROOT/src/`.
- `$ROOT/models/` — TRELLIS.2-4B (только веса уровня 512, ~9 ГБ), декодер из
  TRELLIS-image-large, DINOv3 vitl16 (официальный закрыт; открытое зеркало
  `camenduru/…`, safetensors, хеш совпадает с другими зеркалами).
- `$ROOT/gen.py` грузит модели по очереди, в памяти не больше одной большой
  (иначе не хватает ~8 ГБ свободной RAM). `$ROOT/preview.py` — превью.
- Логи и замеры VRAM — `$ROOT/.tmp/run_*.log`, `vram_*.log`.
- Hunyuan3D НЕ ставить: его веса не лицензированы для ЕС/UK.
