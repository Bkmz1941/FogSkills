# UI — журнал изменений

Хронология правок интерфейса. Здесь только ИСТОРИЯ: как что менялось и почему.
Актуальное состояние — в `../UI.md`, дублировать сюда нельзя.

Записи ниже могут ссылаться на старые имена (например `ShowBuildPanels`
до рефакторинга 2026-08-15) — это нормально, они историчны.

## Записи

- **2026-08-15 (ночь, рефакторинг)** — **`ShowBuildPanels(8 bool)` →
  `ShowBuildPanel(BuildPanel)`.** Ленты нижнего бара делят одну зону и всегда
  взаимоисключающи, а показ принимал восемь позиционных флагов — порядок
  аргументов ошибался молча. Теперь enum `BuildPanel { None, Build, Objects,
  Vegetation, Animations, Special, Models, Environment, Clothes }`, панель и
  вариант её кнопки синхронит один хелпер `SyncToolPanel`, а «включает ли лента
  режим стройки» — предикат `BuildsWorld` (Анимации и Одежда — просмотр, не
  стройка). В записях лога НИЖЕ встречается старое имя — это история.
  Заодно: `UiTheme.RowHeight` (48) и `UiTheme.PopupButtonW` (120) вместо
  россыпи литералов; `UiFactory.ClickableRect` — общий костяк текстовой,
  иконочной и глифовой кнопок; `UiFactory.Modals.cs` — модалки/попапы своим
  файлом; `InventoryScreenUI` разнесён на ядро + `Drag` + `Silhouette`,
  `InventoryItemView` и `ClothesDragSource` переехали в свои файлы (для
  MonoBehaviour имя файла = имя класса — так их можно вешать и в инспекторе).

- **2026-08-14** — **дебаг: DebugView удалён, панель действий F1 — в табах.**
  (1) `DebugOverlayHud.cs` («DebugView», панель статов FPS/позиция/камера
  470×244 сверху-справа) стёрт целиком; F2 теперь только подписи UI-элементов.
  (2) Панель `DebugActions` разрослась (12+ кнопок одной колонкой) и залезала
  на нижнее меню — действия сгруппированы в табы «Вид»/«Игрок»/«Монстры»
  (детали в разделе «Дебаг: хоткеи F1/F2/F3»); максимум 6 строк на вкладке,
  панель 300 шириной, якорь −16/−112 (под FPS-чипом 96×30 @ −16/−72).

- **2026-08-14** — **кнопка «Окно (домашний)» удалена** (просьба Ильи):
  была полным дубликатом «Окна» — тот же `WindowStyle.White`, отдельного
  домашнего стиля в enum нет. Осталось два окна: «Окно» (White) и
  «Окно (панорама)» (Panoramic). Сейвы не затронуты (стили не менялись).
  Заодно по правилу «иконка по центру квадрата» убран сдвиг −6px иконки
  в ячейке квикбара.

- **2026-08-13** — **иконки предметов (Lucide PNG).** Решение по формату: SVG в
  Unity не тащим (vector-graphics — вечный preview), иконки — белые PNG 128px
  на прозрачном в `Resources/Icons`, тинт кодом (готовый пайплайн `Icons`).
  Исходник — глифы уже лежащего в проекте `Lucide.ttf` (рендер fontTools+PIL,
  скрипт одноразовый). `ItemDef.icon` (имя спрайта): рантайм-предметы в
  Items.cs (key→key-round, flashlight, turtleneck→shirt), ассеты —
  vest→shirt, bag_backpack→backpack, apple, bottle→bottle-wine, crate→box,
  plank→fence; джинсы и тетрис-тестовые без иконок (в Lucide нет штанов).
  Рендер: `InventoryScreenUI.AddItemIcon` — белая иконка 0.6·Cell в занятой
  клетке, ближайшей к центру bbox фигуры (текст-подпись остаётся только у
  предметов без иконки); слот экипировки — белая иконка 0.7 размера поверх
  цветного чипа; квикбар — тинт-иконка цвета предмета 30px вместо цветного
  квадратика (без иконки — прежний квадратик).

- **2026-08-13** — **инвентарь: отступы на токенах, правая панель по ширине
  сетки.** Жалоба Ильи: справа «всё прилипло» — фикс-ширина внешней панели
  (340) была УЖЕ 5-колоночной сетки шкафа (5·65+3=328 при 324 полезных):
  грид резался маской и сидел на краю экрана. `InventoryScreenUI`: ширина
  внешней панели теперь считается от её сетки (`ExternalPanelWidth` =
  сетка + Pad вьюпорта + PanelPad с каждой стороны, конста `RightWidth`
  удалена); у обоих скроллов контент получил внутренние поля
  (`PadScrollContent` — padding VStack'а = Pad, в сумме с Pad вьюпорта 16
  от края панели); зазоры между колонками — `PanelGap = 2·Pad`. Магия
  заменена токенами: заголовок/список левой панели на `PanelGap`/`HeaderH
  56`, ряд слота — `SlotRowH 64`/`SlotIconSize 52`/`UnequipW 88`
  (кнопка «Снять» высотой `ControlHeightSm`, инсет `Pad`), подпись — от
  этих же токенов; секция: зазор заголовок→сетка и низ блока = `Pad`
  (было 6/14).

- **2026-08-13** — **блок «Вид» удалён; лампы — тумблер в дебаге.**
  `ViewModeHud.cs` удалён целиком (колонка 1/2/3 слева-снизу + флайаут слоёв
  у кнопки «2»). Режим вида больше не переключается из UI — всегда дефолт
  `ViewState.Mode = Cutaway`; `ViewMode`/`ViewState` не тронуты (их читает вся
  видимость). Слой ламп (`ViewState.ShowLamps`, бывшая лампочка в флайауте «2»)
  теперь тумблер **«Лампы на потолке»** в дебаг-панели F1
  (`RebuildDebugActions` → `ToggleRow`). Квикбар сдвинут к левому краю
  (`QuickbarX = Pad`), `SectionRowLeftInset` пересчитался сам.

- **2026-08-13** — **панель «Текстуры»: таб «Потолок» удалён совсем** (решение
  Ильи). Из `TexTabs`, `TabFolder`, `ApplyTexture` убраны все ветки `roof`;
  глобальный сеттер потолка (`SetCeilingTexture`) из UI больше не доступен,

  `_floodGhosts`, клик — `StairPiece.SetTopPaint`.

- **2026-08-13** — **рефактор нижнего меню: отступы и размеры на токенах.**

  общие консты `QuickbarX/W/H`, из них выводится `SectionRowLeftInset`

  `SidePanelY` (=BarH+QuickbarH+2·Pad) — панель «Текстуры» теперь встаёт над
  квикбаром по формуле (было 330f). Карточки Selection/Placement и попап лифта —
  на `BottomMenuH` вместо `BarH+MainRowH`/`BarH+60`. Попап лифта — автоширина
  (`ContentSizeFitter`, фикс 438 разошёлся с контентом). Удалён мёртвый
  `UiFactory.Row` на самом `BottomBar` (все дети — `ignoreLayout`).
  Кнопки анимаций «Стоп» 100→`ToolBtnW`, чип одежды 168→`ModelBtnW`
  (свотч/отступы чипа тоже на токенах). Крестик текстур/модалок 40×40 →
  `ControlHeightSm`, офсеты −6/−8 → −`Pad`. Визуальные сдвиги ≤4px
  (квикбар-ячейка 58→56, «Отмена» в «Сменить уровень» 44→40 высотой).

- **2026-06-27** — **система кнопок в стиле shadcn/ui (тёмная тема, без ассетов).**
