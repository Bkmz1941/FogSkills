# Карта «Окрестности «Сосен»» — спецификация для Unity

_27.10.2026. Снято с опубликованной страницы (версия 51) и её кода `tavern-level1/map/sosny_map.html`.
Цель: воспроизвести ту же карту внутри игры «Таверна» (Unity 6.3, C#), не заглядывая в веб-код.
Числа ниже — ровно те, что в странице; где сказано «px», имеется в виду пиксель экрана при текущем масштабе._

## 1. Единицы, координаты, мир

- Мир — квадратная сетка **N = 16 × 16 квадратов (tile)**, квадрат = **1 км**.
- Координаты объектов — в квадратах, дробные: `x ∈ [0, 16)`, `y ∈ [0, 16)`, **ось y вниз** (как на экране / к югу).
  `0.001` квадрата = 1 м. Все координаты в базе округлены до `0.0001` (10 см).
- Имя квадрата: буква столбца `A…P` (x = 0…15) + номер ряда `1…16` (y = 0…15). `G7` ↔ x∈[6,7), y∈[6,7).
- **Перевод в Unity** (1 юнит = 1 м, x — восток, z — север):
  `ux = x·1000`, `uz = −y·1000` (или `(16 − y)·1000`, чтобы весь мир был в положительных z). Повороты `rot` в карте —
  градусы по часовой стрелке на экране (y вниз); в Unity вокруг оси Y это тот же знак при `uz = −y·1000`.
- Сетка игры 3 м: квадрат карты = 333 ⅓ клетки. Уровень 1 игры (73×56 клеток ≈ 220×170 м) — это ~1/20 квадрата карты.
  То есть карта — **карта округи** (локации, дороги, ориентиры), а не раскладка одного уровня.

## 2. Камера и приближения

- Камера **не выходит за карту**: видимый прямоугольник всегда внутри `[0,16]²` (центр камеры зажат так, чтобы края
  экрана не пересекали границу мира). Квадрат A1 — крайний верхний левый.
- Ровно **три фиксированных приближения**, переключаются кнопками 1/2/3, колесом (шаг = один уровень, с задержкой 200 мс),
  двойным щелчком (ближе, вокруг точки), клавишами `1 2 3`, `+ −`. Приближение к точке сохраняет мировую точку под курсором.
- Масштаб `k` (px на квадрат):
  - **3 (далеко)**: `k3 = max(W/16, H/16)` — вся карта покрывает экран целиком (cover), W×H — размер экрана в px;
  - **1 (близко)**: `k1 = max(2.5·k3, H − высота_панели − 24)` — один квадрат помещается в высоту над панелью инструментов;
  - **2 (средне)**: `k2 = √(k1·k3)`.
  В коде индексы `level`: 0 = «1», 1 = «2», 2 = «3»; все массивы размеров ниже идут **[близко, средне, далеко]**.
- Линейка масштаба внизу справа: подбирается наибольший шаг из `20 м … 10 км`, который не длиннее 100 px.
- Подписи сетки: буквы столбцов по верхнему краю экрана, номера рядов по левому (удерживаются у края, когда граница мира
  за экраном), шрифт 500 11px, белый ореол.

## 3. Квадраты и «нет данных»

- Коллекция `tiles`: документ с id = имя квадрата, `{ on: bool }`. Нет документа = выключен.
- Выключенный квадрат: заливка `#F1F3F4` с диагональной штриховкой `#E1E4E8` (шаг 12 px, линия 1.5 px),
  надпись «Нет данных» (500 16/13 px на уровнях 1/2) и имя квадрата под ней; на уровне 3 — только имя (500 11px). Цвет текста `#80868B`.
- Выключенный квадрат **перекрывает всё**: объекты внутри него не рисуются и не кликаются (штриховка рисуется поверх объектов).
  Объект, лежащий в двух квадратах, виден только в включённой части.
- Включённый: земля `#F8F9FA`, в левом верхнем углу имя квадрата (500 14/12 px на 1/2, нет на 3), отступ 8×7 px.
- Линии сетки между квадратами `#DADCE0` 1 px всегда; рамка мира `#BDC1C6` 1.5 px.
- Подсветка наведения квадрата (когда инструмент не выбран): заливка `rgba(26,115,232,0.06)` + рамка `rgba(26,115,232,0.5)`;
  выбранный квадрат: `rgba(26,115,232,0.10)` + рамка `#1A73E8` 2 px. Щелчок по пустому месту выбирает квадрат и показывает
  его настройки (вкладка «Квадрат»: «Данные вкл / Данные выкл»).
- В Unity естественное соответствие: квадрат = чанк/локация 1×1 км; флаг `on` = «локация готова / есть данные».

## 4. Схема данных — коллекция `features`

Один документ на объект. Общие поля: `kind` (строка), `t` (время создания, мс; определяет порядок отрисовки внутри
своего слоя). Координаты — в квадратах. `pts` — плоский массив `[x0,y0,x1,y1,…]`.

| kind | Поля | Смысл |
|---|---|---|
| `road` | `style` ∈ `highway`,`road`,`dirt`,`path`; `pts` (≥2 точек); `dir` ∈ −1,0,1 | дорога по точкам; `dir` 0 двустороннее, 1 одностороннее по ходу точек, −1 против |
| `area` | `style` ∈ `forest`,`lawn`,`water`,`field`,`swamp`,`sand`; `pts` (≥3) | замкнутый участок |
| `hill` | `pts` (подножие, ≥3); `h` высота в м (целое, может быть < 0 = овраг); `color` ∈ `green`,`brown`; `px`,`py` вершина (необязательно) | холм горизонталями |
| `building` | `x`,`y` центр; `w`,`h` стороны в квадратах (0.03 = 30 м); `rot` градусы; `fl` этажей (1…30) | здание-прямоугольник |
| `tree` | `x`,`y`; `type` ∈ `tree`,`fir`,`pine`,`bush` | дерево; точка = основание ствола |
| `poi` | `x`,`y`; `type` ∈ `busstop`,`church`,`place`; `text`; `lv` ⊂ {1,2,3}; `color` hex (только place); `img` id фото (32 hex) | место со значком |
| `label` | `x`,`y`; `text`; `size` ∈ `big`,`mid`,`small`; `rot`; `lv` ⊂ {1,2,3} | название (город, посёлок, улица) |
| `wlabel` | `pts` (≥2); `text`; `lv` ⊂ {1,2,3} | название воды вдоль линии |
| `bench` | `x`,`y`; `rot` | лавочка |

`lv` — на каких приближениях объект/надпись показывается (1 = близко … 3 = вся карта). Нет поля = `[1,2,3]`
(у старых `label` — один уровень по прежнему размеру: big→3, mid→2, small→1).

Выгрузка текущей базы: `tavern-level1/map/export/tiles.json` и `features.json` — массивы документов `{id, data, version}`
как их отдаёт ArtifactData. Для Unity проще всего сложить это в `MapData` (ScriptableObject или JSON в `Resources`) с
теми же полями; `JsonUtility` не умеет полиморфизм — держать плоские классы с необязательными полями (как `LevelData`).

## 5. Порядок слоёв (снизу вверх)

1. Земля `#F8F9FA`.
2. **Участки** (`area`) в порядке `t`.
3. **Холмы** (`hill`).
4. **Дороги** — сначала все обводки, потом все заливки, по классам: тропа < грунтовка < дорога < шоссе
   (главная перекрывает второстепенную; перекрёстки одного класса без шва, потому что обводки рисуются до заливок).
   Стрелки односторонних — поверх заливок.
5. **Здания** (отсортированы по `y`: южнее = ближе = поверх).
6. **Лавочки**.
7. **Деревья** (отсортированы по `y`).
8. **Места** (значок + название).
9. **Названия воды** (вдоль линий).
10. **Названия**.
11. Выделение (ореолы), заглушки выключенных квадратов (поверх всего), линии сетки, подписи сетки, рамка выбора.

## 6. Отрисовка объектов — числа и цвета

### 6.1 Дороги
- Геометрия: точки сглаживаются **Catmull-Rom** (α = 0.5 по формуле ниже), 8 сэмплов на сегмент, концы — дублирование крайних точек;
  две точки — прямая. Формула для сегмента p1→p2 с соседями p0, p3, `t∈[0,1)`:
  `0.5·(2p1 + (p2−p0)t + (2p0−5p1+4p2−p3)t² + (3p1−p0−3p2+p3)t³)`.
- Ширина **в px экрана** (не в метрах), концы круглые, стыки круглые:

| style | заливка | обводка | ширина px [1,2,3] | штрих |
|---|---|---|---|---|
| highway Шоссе | `#F9D77E` | `#E3B54A` | 24 / 14 / 6 | — |
| road Дорога | `#FFFFFF` | `#C6C9CE` | 16 / 9 / 4 | — |
| dirt Грунтовка | `#EADFC6` | `#CDBE9D` | 11 / 6 / 2.5 | — |
| path Тропа | `#9AA0A6` | нет | 3.5 / 2 / 1 | пунктир [3w, 2.2w] |

  Обводка = заливка шириной `w + 2.5` px цветом обводки под заливкой. **На уровне 3 тропы не рисуются и не кликаются.**
- Выделенная дорога: под обводкой ореол `rgba(26,115,232,0.35)` шириной `w + 10`.
- **Стрелки** (`dir ≠ 0`, уровни 1–2): шевроны вдоль сглаженной линии с шагом **160 px** (уровень 1) / **110 px** (уровень 2),
  первый на половине шага; размер `s = max(2.5, 0.28·w)`; шеврон — ломаная `(−0.5s, −0.6s) → (0.35s, 0) → (−0.5s, 0.6s)` в системе
  касательной, линия `max(1, 0.08·w)` px, цвет `rgba(60,64,67,0.55)`; при `dir = −1` повёрнут на 180°. Если длина линии < шага — стрелок нет.
- В Unity: сплайн по тем же точкам (Catmull-Rom), полоса фиксированной экранной ширины — проще всего LineRenderer/меш-лента
  с шириной, пересчитываемой при смене уровня (`w_world = w_px / k`), или шейдер с экранной шириной.

### 6.2 Участки
- Многоугольник с **скруглёнными углами**: у вершины `c` с соседями `a`, `b` радиус `r = min(0.1 квадрата (100 м), |ca|/2, |cb|/2)`;
  контур идёт прямой до точки `c + (a−c)/|a−c|·r`, затем квадратичной кривой с контрольной точкой `c` до `c + (b−c)/|b−c|·r`.
  **Вершина, лежащая на границе квадрата** (|x − round(x)| < 0.012 или то же по y), **остаётся острой** — лес, залитый на весь квадрат,
  стыкуется с его краем без щелей.
- Цвета:

| style | заливка | контур 1 px |
|---|---|---|
| forest Лес | `#C6E6C6` | `#B0D6B0` |
| lawn Поляна | `#E4F1D6` | `#CFE3BC` |
| water Вода | `#AADAFF` | `#92C8F2` |
| field Поле | `#F0ECD6` | `#E2DCC0` |
| swamp Болото | `#D2E6DA` | `#B5D2C1` + штрихи |
| sand Песок | `#F3E7C6` | `#E4D4A6` |

- Штрихи болота (уровни 1–2, внутри контура): горизонтальные чёрточки `rgba(96,150,128,0.7)` 1.2 px, сетка в мировых координатах
  с шагом **12 м** (уровень 1) / **30 м** (уровень 2), ряды через один сдвинуты на полшага, длина чёрточки 0.45 шага; на уровне 1 над каждой
  ещё короткая вторая (0.4 длины, на 3 px выше).
- Выделение: контур `#1A73E8` 2.5 px по тому же скруглённому пути.

### 6.3 Холмы
- Вершина `peak` = `(px,py)`, если заданы, иначе центроид вершин подножия.
- Число горизонталей `n = clamp(round(|h| / 10), 2, 30)`; i-я горизонталь (`i = 1…n−1`) — подножие, **сжатое к вершине**
  с коэффициентом `s = 1 − i/n`: `p' = peak + (p − peak)·s`, со скруглением углов как у участков.
- Цвета (`color`):

| | оттенок (уровни 1–2) | оттенок (уровень 3) | линия | каждая 5-я |
|---|---|---|---|---|
| green (по умолчанию) | `rgba(160,196,150,0.35)` | `rgba(140,180,130,0.14)` | `#6FA070` 1 px | `#4E8352` 1.6 px |
| brown | `rgba(222,208,180,0.45)` | `rgba(205,188,155,0.18)` | `#C9B48E` 1 px | `#B39A6E` 1.6 px |

- Уровни 1–2: оттенок подножия + горизонтали + контур подножия 1 px + подпись высоты «60 м» (500 11px, цвет «каждой 5-й», белый ореол 3 px) в вершине.
  **Уровень 3: только слабый оттенок**, без линий. `h < 0` (овраг): все линии пунктиром `[4,3]`.
- Выделение: контур подножия 2.5 px синий; ручки точек подножия; жёлтая ручка вершины `#F2B33D` с обводкой `#8A6A2E` радиус 7 px.
- В Unity: тот же алгоритм даёт полилинии горизонталей; при желании — реальный рельеф: высота в точке = `h · (1 − d)`,
  где `d` — доля «сжатия», при которой точка попадает на контур (0 в вершине, 1 на подножии). Это согласуется с `TerrainHeights`
  игры лишь по смыслу (у игры предел ±6 м на уровне), карта — ориентир для высот локации.

### 6.4 Здания
- Подошва — прямоугольник `w × h` (в квадратах), центр `(x,y)`, поворот `rot` (по часовой). Углы: `(±w/2, ±h/2)` повёрнуты и сдвинуты.
- **Объём «как в Яндексе»**: крыша поднята по экрану вверх на `lift = fl · 0.0032 · k · 0.8` px (`k` — px на квадрат; т.е. этаж ≈ 2.56 м
  в экранном масштабе ×0.8); на уровне 3 `lift = 0`; **выбранное здание рисуется плоским** (`lift = 0`), чтобы ручки совпадали с подошвой.
  Рисуется, если `lift > 0.8 px`: тень — подошва, сдвинутая на `(+0.5·lift, +0.35·lift)`, `rgba(60,64,67,0.12)`; четыре стены — четырёхугольники
  между ребром подошвы и ребром крыши, отсортированы по средней `y` ребра (дальние первыми); цвет стены `#D5CCBD`, осветлён/затемнён на
  `0.18·light`, где `light = 0.5·(−nx) + 0.3·(−ny)` по нормали ребра (свет слева-сверху); обводка стен `#C9C1B2` 0.8 px.
- Крыша: заливка `#ECE7DE`, обводка `#C9C1B2` 1 px (0.5 px на уровне 3). **Наведение**: крыша `#FBF1D4`, обводка `#8AB4F8` 1.5 px.
- Выделение: контур подошвы `#1A73E8` 2.5 px; 8 ручек размера (4 угла r=6, 4 середины сторон r=4.5); растяжение за ручку двигает только
  свою сторону (стороны), противоположная стоит, в системе координат здания; минимум стороны 3 м. Размер показывается в метрах.
- Этажи `fl`: по умолчанию 2 у новых; в Unity ≈ `fl` этажей по 3 м (сетка игры) — для генерации коробки дома.
- В Unity: коробка `w·1000 × fl·3 × h·1000` м, повёрнутая на `rot`; в «карточном» виде — экструзия 2.5D с теми же цветами.

### 6.5 Деревья
- **В масштабе карты**: радиус кроны `R = 0.03 квадрата = 30 м` → `r = R·k` px. Если `r < 4 px` — просто точка цвета кроны радиуса `r`.
- Иначе стоит «в рост»: тень — эллипс `(x + 0.35r, y + 0.1r)`, радиусы `0.9r × 0.32r`, `rgba(60,64,67,0.16)`; ствол `#7A5636`; крона над точкой:

| type | крона | контур | форма |
|---|---|---|---|
| tree Дерево | `#A7D2A5` | `#82B382` | круг r в центре `(x, y − 1.1r)`, ствол шириной 0.24r от земли до центра, блик `rgba(255,255,255,0.3)` r·0.38 слева-сверху |
| fir Ель | `#8DC28F` | `#699F6C` | ствол 0.2r×0.6r; три треугольника (полуширина/низ/верх в r): (1.0, −0.3, 1.1), (0.78, 0.5, 1.9), (0.52, 1.2, 2.6) — y отсчитывается вверх от точки |
| pine Сосна | `#B2D6A3` | `#8CB882` | ствол 0.22r до `y − 1.6r`; крона — эллипс `0.95r × 0.7r` в `(x, y − 1.6r)`, блик |
| bush Куст | `#B9DEB3` | `#93C28F` | без ствола; эллипс `0.85r × 0.6r` в `(x, y − 0.3r)`, блик |

- Контур 1 px, рисуется только при `r ≥ 4`. Деревья сортируются по `y` (южные поверх). Цвета нарочно **чуть темнее леса** `#C6E6C6`.
- Выделение: окружность вокруг центра кроны радиуса `1.1r + 5`.
- В Unity: билборд/простой префаб; крона 30 м — стилизация карты, в игре дерево обычное (~8–12 м), карта хранит только позицию и вид.

### 6.6 Места (poi)
- Значок: круг радиуса **13 / 10 / 6 px** (×1.15 при наведении), цвет по типу: остановка `#1A73E8`, храм `#8E63B5`, место `#F29900`
  (у места цвет выбирается: серый `#5F6368`, красный `#D93025`, оранжевый `#F29900`, зелёный `#188038`, синий `#1A73E8`, фиолетовый `#8E63B5`);
  белая обводка 1.5 px; тень — тот же круг со сдвигом (1, 2) `rgba(60,64,67,0.25)`.
- Пиктограмма белым внутри (уровни 1–2): остановка — автобус (скруглённый прямоугольник 1.1r×0.95r, окно цветом значка 0.72×0.36, два колеса r·0.14);
  храм — крест (вертикаль ±0.72r, перекладина ±0.48r на −0.18r, верхняя малая ±0.26r на −0.5r, нижняя косая от (−0.3r, +0.42r) к (+0.3r, +0.22r), линия 0.22r);
  место — пятиконечная звезда (внешний радиус 0.62r, внутренний 0.28r).
- Название: 500 12px (11 на уровне 3) `#3C4043`, белый ореол 3 px, слева от значка на `r + 5` px, по вертикали по центру.
  Хит-бокс = круг значка ∪ прямоугольник текста.
- Видимость: показывается только на уровнях из `lv`; выделенное показывается везде с прозрачностью 0.4.
- **Карточка** (попап): белая, ширина 240 px, скругление 10, тень; сверху фото (140 px высоты, cover) или цветная полоска 4 px цвета значка;
  строка: название 500 14px + крестик «×» справа (без кружка, 22×20 px); ниже только «Фото пока нет» (11px, серый) и только в режиме
  Стройки, пока фото не загружено. Позиция: справа от значка (`x + r + 12`, `y − 28`), если не влезает — слева; зажата в экран с полями 12 px;
  едет вместе с картой. **Пока карточка открыта, название этого места на карте не рисуется.**
  В Стройке карточка следует за выбранным местом; в Просмотре открывается щелчком по месту, закрывается крестиком или щелчком мимо.
- Фото: файл ужимается до 1024 px по большей стороне, JPEG 0.85, хранится в assets артефакта; в документе — id. Для Unity: выгрузить
  картинки отдельно (`/_blob/<id>` с аккаунта владельца) и положить рядом с `features.json` как `<id>.jpg`.

### 6.7 Названия (label)
- Один инструмент; у каждого названия размер:

| size | шрифт | цвет | особенности |
|---|---|---|---|
| big | 700 20px | `#3C4043` | ВЕРХНИЙ РЕГИСТР, межбуквенный интервал 0.08em |
| mid | 500 15px | `#5F6368` | — |
| small | 400 12px | `#70757A` | — |

- Белый ореол 4 px, по центру точки, **наклон `rot`** (градусы по часовой). Видимость по `lv`; выделенное — везде с прозрачностью 0.4,
  рамка выделения пунктиром по повёрнутому прямоугольнику текста (+5 px по бокам, +4 сверху/снизу).
- Шрифт страницы — Roboto (Google Fonts), запасной Arial.

### 6.8 Названия воды (wlabel)
- Текст **вдоль линии**: линия сглаживается как дорога; если конец левее начала — линия разворачивается (текст читается слева направо);
  шрифт `italic 500` **15 / 13 / 11 px**, цвет `#3B7DBF`, белый ореол 3 px, межбуквенный интервал 0.1 размера; текст центрируется по длине
  линии, каждая буква ставится в своей точке линии и поворачивается по касательной.
- Если длина линии на экране `< ширина текста + 12 px` — текст рисуется **прямо**, одной строкой, в середине линии (по длине), повёрнутый
  по направлению начало→конец (угол приведён в (−90°, 90°]).
- Видимость по `lv`. Выделение — полупрозрачная синяя полоса вдоль линии шириной `размер шрифта + 8`.

### 6.9 Лавочка
- Фиксированный экранный размер: длина **22 / 13 px**, на уровне 3 не рисуется. Повёрнута на `rot`. В локальных координатах (длина L):
  тень прямоугольник `(−L/2+2, −0.1L+3, L, 0.32L)` `rgba(60,64,67,0.18)`; ножки `#4A4440` `(−0.42L, −0.1L, 0.08L, 0.3L)` и `(0.34L, …)`;
  спинка `#8F6540` `(−L/2, −0.28L−h, L, 0.14L)`; сиденье `#B07F52` `(−L/2, −0.1L−h, L, 0.26L)` + блик 0.06L; `h = 0.12L`. Наведение: сиденье `#C99667`, рамка `#8AB4F8`.

## 7. Взаимодействия (для редактора в Unity, если он нужен)

- **Режимы**: Просмотр (прокрутка, зум, наведение на дома, карточки мест) / Стройка (всё ниже). Запоминается.
- **Инструменты по вкладкам**: Квадрат · Дороги (4 покрытия) · Здания · Природа (4 дерева, 6 участков, холм) · Места (3 значка + лавочка) · Подписи (Название, Вода).
- **Рисование по точкам** (дорога, участок, холм, название воды): щелчок — точка; Enter / двойной щелчок / правый щелчок — готово; Esc — отмена;
  Ctrl+Z — убрать последнюю точку; у участков щелчок по первой точке замыкает. Черновик — синяя линия 2 px с точками (первая крупнее), пунктирный хвост к курсору.
  Точки ближе 3 px друг к другу схлопываются; дорога ≥ 2 точек, участок/холм ≥ 3.
- **Здание**: протянуть прямоугольник (≥ 6 px), центр и стороны считаются по осям, `rot = 0`, `fl = 2`.
- **Выбор**: щелчок; порядок попадания: места → названия → лавочки → деревья → здания (подошва или крыша) → названия воды → дороги → холмы → участки;
  внутри выключенного квадрата ничего не выбирается. Shift+щелчок добавляет/убирает; Shift+протяжка — рамка (попадание по якорю: точка объекта
  или центроид многоугольника). Переключение вкладки, Esc, смена инструмента — снимают выбор.
- **Правка выбранного**: дороги/участки/холмы/линии воды — ручки вершин (r 6) тянутся, полупрозрачные ручки середин рёбер (r 4) добавляют вершину,
  Alt+щелчок убирает (минимум 2 у линий, 3 у многоугольников); здание — тянуть за крышу/подошву (перенос), 8 ручек размера, поворот ±15° кнопками
  и клавишей R / Shift+R, этажи ±1; дерево/место/название/лавочка — перенос; название и лавочка — поворот как у здания; холм — ±10 м, цвет, вершина, перенос целиком за тело (точки и вершина сдвигаются вместе, порог 3 px, одно действие отмены; с 28.10);
  место — тип, цвет (у звёздочки), «Видно на 1 2 3», название, фото; дорога — покрытие и направление; участок — тип; название — размер, наклон, 1 2 3.
- **Вкладка «Квадрат»**: щелчок всегда выбирает квадрат под курсором — объекты на этой вкладке не наводятся, не выделяются и не тянутся; «Данные выкл» меняет только `tiles/<имя>.on`, документы `features` не трогает (с 28.10).
- **Группа**: перенос всех, Delete, Ctrl+C/Ctrl+V для зданий (копируются взаимные положения; вставка под курсор или со сдвигом).
- **Отмена**: каждое действие — пара «до/после» документа (null = нет); группа — список пар; Ctrl+Z/Ctrl+Shift+Z/Ctrl+Y; глубина 100.
- **Клавиши**: 1 2 3, + −, стрелки (сдвиг на 80 px), Esc, Enter, Delete/Backspace, R, Ctrl+Z/Y/C/V.

## 8. Соответствие сущностям игры (ориентир для планирования)

| На карте | В игре («Таверна») | Как думать о переносе |
|---|---|---|
| квадрат 1 км, `tiles.on` | локация/миссия (уровень `level.json` ~220×170 м — часть квадрата) | квадрат = район; «данные вкл» = район описан; внутри квадрата может быть несколько уровней-точек |
| `road` | `env_highway` и тропы уровня; дороги между локациями | трасса дороги — ориентир для въезда/выезда уровня (`fog_out_*`, остановка `bus_stop`) |
| `area` лес/вода/поле | растительность (`BUILD.md` «Растительность»), вода в рву, текстуры земли | чем залит квадрат вокруг локации; фон за границей уровня (декор-зона) |
| `hill` + `h` | `TerrainHeights` (предел ±6 м на уровне) | высоты относительные; гора `mountain_top` уровня 1 — это холм карты |
| `building` `fl` | дом из плит и стен (сетка 3 м, этаж 3 м) | размер в метрах → клетки (÷3), этажи → уровни L = 0,3,6 |
| `tree` | деревья уровня (~1300 на уровне 1) | карта хранит только заметные/одиночные; лес как участок |
| `poi` остановка/храм/место + фото | `bus_stop`, ориентиры сюжета (`tavern-story`), фото — для карточки в игровом UI | карточка = тот же белый попап в HUD-карте |
| `label`, `wlabel` | названия на игровой карте | три уровня детализации = три зума игровой карты |
| `bench` | объект-лавочка (создавать по `tavern-objects`) | мелкие объекты карты = пропы локации |

Варианты реализации в Unity (решает Илья): **(а)** карта в HUD/меню — отдельная 2D-сцена на UGUI/Canvas или ортокамера с мешами,
читающая `MapData`; **(б)** генерация черновика `level.json` по квадрату (дороги → `env_highway`, участки → текстуры/растительность,
здания → коробки стен/плит по рецептам `BUILD.md` «Сборка уровня файлом», холмы → `heights`); **(в)** оба: карта как навигация между
локациями + заготовка локации. Для (а) достаточно разделов 1–6; для (б) нужны ещё правила `tavern-build` и `tavern-objects`.
