## Как гонять

1. **Тесты (EditMode, редактор вне play):** `python3 ~/.claude/skills/tavern-regress/probes/cycle.py compile` → `cycle.py tests`. Классы общения: `TalkRegressTests` (05.11), `CatalogTests` (файлы персонажей, тексты без точки и тире, примеры), `AiMonsterBriefTests` (фазы, шкала, нравится), `LifeRulesParseTests` (правила общения). Пока Илья в play с несохранённым уровнем — не останавливать (`cycle.py stop` откажет, P843), только `offline_build.py`.
2. **Тексты:** `python3 ~/.claude/skills/tavern-talk/tidy_check.py` — 0, «чисто».
3. **Смысл:** `python3 ~/.claude/skills/tavern-talk/intent_bench.py valera` — ≥ 90 % (05.11: 65/72). Нужен llama-server :11435 (игра в play или руками — см. tavern-talk), после — `pkill -x llama-server`.
4. **Play-кейсы (⏳):** по `CASES.md`, данными через `mcp_call.py execute_code` (`Talk.Lines`, `Talk.MemoryOf`, `Talk.TenseZone/Night`, журнал `~/.config/unity3d/DefaultCompany/Tavern/talklogs/valera.txt`). Готовые приёмы:
   - герой рядом и разговор: телепорт `PlayerRef.Transform` (выключить `CharacterController`), `Talk.Start(v)`, `Talk.Ask("…")`, ждать 4–8 с;
   - запретная зона: героя в `kiosk_inside` (133.6, 0.05, 51.6), Валеру рядом; выйти — (132, 0.05, 47.6);
   - ночь без перевода часов: `Talk.SetNight(v, true)` перед `Ask` (часы каждый тик возвращают настоящее);
   - шум: `Cozy.Creatures.Noise.Burst(NoiseLevel.Normal, 3f)` рядом со спящим. ⚠️ Спящий по ПРОБЕ (`Run` поверх круга) реакций общей группы не получает (`Outranks`) — укладывать настоящей группой;
   - ⚠️ `Weather.Hour = X` откатывается часами игры, но успевает запустить группы по времени (Валера днём лёг спать) — не делать или убирать за собой.
5. **После:** память Валеры вернуть (`Talk.Forget` только если кейс её портил), раскладушку — на место, героя — туда, где был.

## Правила набора

Детерминизм (модель выключена `Talk.UseModel = false` для кейсов заготовок), память чистая на входе, проверка по данным, а не по экрану. Новая механика общения = новая группа кодов в `CASES.md` + тест в `TalkRegressTests` (что разбирается и что лежит в файле персонажа) + строка в `tavern-talk/SKILL.md`.
