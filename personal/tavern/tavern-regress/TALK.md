# Общение с персонажами: регресс по группам

⭐ Илья 04.11: «оч много функционала — нужен скил и детальный регресс с кучей примеров для регресса и проверок». Домен — скил `tavern-talk`; область граблей — `общение` (`bugs.py общение`). Персонаж для проверок — Валерий Шилов (`valera`, существо `valera_1`, `Dialogs/valera.json`: шкала ±24, рост за день +6).

**Стенд:** уровень, открытый у Ильи (уровень не менять — правило `tavern-game`). Валеру спавнить пробой только в play (`Application.isPlaying` в том же вызове), убрать за собой. Модель: живая (`LlmBridge.Online`) для кейсов «отвечает модель», выключенная (`Talk.UseModel = false`) — для детерминированных кейсов.

## Правила набора

1. **Детерминизм прежде всего.** Кейсы на заготовки, шкалу, фазы, просьбы, правила — без модели (`UseModel = false`); шансы — через `OfferChance`/`TopicChance` = 1 или 0 на время кейса, вернуть.
2. **Память — чистая на входе.** Перед кейсом `Talk.Forget("valera")` (или кнопка «Стереть» в F1 → ИИ → «Персонажи»), после — тоже.
3. **Проверять по данным, а не по экрану:** `Talk.MemoryOf("valera")` — `score`, `phase`, `phases` (история), `log`, `active`, `done`, `declined`, `topics`; `Talk.Lines` — реплики текущего разговора; `Talk.LastPrompt` — что ушло модели.
4. **Время дня** — `FoodSpoil.Today`; предел роста считается по нему.

## Когда гонять

ДО и ПОСЛЕ правки: `Talk.cs`, `LevelIO.cs` (блок `TalkMemoryData`), `LifeRules.cs`/`LifeRules.Parse.cs` (события и действия общения, заголовки групп), `CreaturePlan.cs` (шаги `talk`/`attitude`), `MonsterCardUI.cs`, `InventoryScreenUI*.cs` (режим «передать»), `HudUI.Talk.cs`, `SpeechBubbles.cs`, `HudUI.Examine.cs`, любой `Dialogs/*.json`.

Команды: `python3 ~/.claude/skills/tavern-regress/probes/cycle.py compile` → `cycle.py tests` (EditMode); офлайн в play — `offline_build.py`. Живая проба `talk_probe.cs` — в очереди.

## Примеры для ручного прогона в play (одним заходом)

1. F1 → ИИ → «Персонажи» → Валера → «Стереть». Модель выключить («Нет типового ответа — отвечает модель»).
2. Поговорить: «привет» → TK-A01. «где лодки?» → «У причала. Только они на ремонте, не дам.»
3. Ползунок «Отношение» на 12 → «привет» → TK-A02. На −10 → «где лодки?» → TK-A03.
4. «Отдайте тетрадь!» → ответ прежней фазы, в истории «−2 … повышают голос» → TK-L01.
