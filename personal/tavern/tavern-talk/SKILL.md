## Решения Ильи (не нарушать)

1. **Валера в день 1 — обычный человек**, в своём уме (04.11: «надо сделать модель — человек, просто человек… на первый день всё вообще норм, потом превращаться начнут»). Превращение — правилами потом. Не нападает.
2. **Герой ему незнакомец**: вежливо, сдержанно, реалистично, без откровений и «раскрытия души»; без заикания; без повторяющихся присказок в конце.
3. **Морина и «хозяина» Валера не называет никогда** — ни в ответах, ни в промпте (блок «СЛОВА, КОТОРЫХ У НЕГО НЕТ»).
4. **Лодки все сломаны**, почему — не рассказывает («на ремонте»). Правда (Пахомов пробил днища №2–4, его увезли на №1) — только записанной фразой в «Дружбе».
5. **Каждый вопрос — свой ответ в каждой фазе**; нет заготовки — отвечает модель.
6. **«!» в реплике героя — повышение голоса, даже один знак** → «не нравится».
7. **Тексты просьб без места и времени**: не «из ларька», «на причале», «под мойкой», «с утра», «со вчера».
8. **Сразу друзьями не стать**: рост за игровой день ограничен; у каждого персонажа своя шкала — кого-то проще склонить к дружбе, кого-то тяжело.
9. **Обычные просьбы — случайно в разговоре** («сам в диалоге говорит, а мы отвечаем — сделаем или нет»); сюжетные выдаём мы.
10. **Реплики над головой висят** до новой реплики любого из двоих, конца разговора или атаки.
11. **В дебаге видно всё**: фаза, счёт, история «что сделал — что изменилось».
12. **Имя — то, каким он назвался** (может соврать): пока не назвался — «Незнакомец» в карточке, субтитрах и репликах; модель всегда знает настоящее.
13. **Значок фазы** (смайлик) справа от карточки существа, как бейджи у объектов; только у мирного — у враждебного в карточке имя и здоровье.
14. **Крики вне разговора** висят над головой N секунд (не до следующей реплики).
15. **Тексты из правил локализуются**: пишутся один раз id (`#till_away`) с RU/EN в файле персонажа или черновиком `«ру» | «en»`.

## Файл персонажа `Dialogs/<id>.json`

Все тексты — `{ "ru": …, "en": … }` (правило 12: без английского задача не закончена, тест красный).

| поле | что |
|---|---|
| `id`, `dashboard`, `name`, `status`, `greeting` | id = имя существа без `_N` (`valera_1` → `valera`); `dashboard` — id на сайте (`shilov`); `status: мирный` |
| `prompt` | характер для модели; в конце — блок «СЛОВА, КОТОРЫХ У НЕГО НЕТ» |
| `tics` | присказки в конец ответа (у Валеры пусто — Илья снял) |
| `pool` | запас, когда модель молчит 8 с |
| `pairs[]` | `group`, `player` (варианты через `/`), `reply`, `from`, `to` — фазы, в которых пара доступна (по умолчанию 0–5). У одного вопроса несколько пар с разными фазами |
| `phases[6]` | как говорит в каждой фазе (идёт в промпт) |
| `likes[]`, `dislikes[]` | `ru`, `en`, `points` (по умолчанию 1), `when` — слова/знаки в реплике героя через `/` (`!`, `пропа/секта/…`) |
| `requests[]` | `id`, `name`, `ask`, `thanks`, `item` (id предметов через `/`, `prefix_` — по началу id), `points`, `from` (фаза), `story` |
| `interests[]` | темы: `id`, `name`, `asks[]` (его вопросы), `points` |
| `openers[]` | первая фраза, когда подходит сам |
| `busy[6]`, `leave[6]` | «занят» и «ухожу по делам» по фазам |
| `refuse[]` | отказ, когда передали ненужное |
| `nameWhen` | слова имени через `/` (`валерий/валера/шилов/valery/…`): прозвучало в его ответе — имя узнано, показывается как сказал |
| `lines[]` | реплики для правил: `id`, `ru`, `en`, `byPhase[6]` (необязательно) — `[shout #id]`, `[talk #id]` |
| `scale`, `dayGain` | размах шкалы (±, по умолчанию 20) и рост за день (по умолчанию 6) |

## Как идёт ответ

1. Реплика героя → журнал (день, время).
2. Если висит тема — ответ по теме даёт баллы (раз в день на тему); «не знаю» / «нет» — ничего.
3. Если висит просьба — ответ героя разбирается текстом (`OfferVerdict`: начало «да / конечно / ладно / принесу / сейчас…» — согласие, «нет / не могу / не сейчас / сам…» — отказ); нетиповой — модель отвечает «да / нет / неясно» (`OfferJudge`); неясно — обычная реплика, просьба висит. Кнопок «Сделаю / Нет» нет (Илья 04.11).
4. Атака по описанию — молча, без ответа.
5. Пара в своей фазе (`from…to`, точное совпадение по `Norm`) → записанный ответ; иначе модель (промпт + фаза + впервые ли/N-я встреча + нравится/не нравится + закрытые темы + чего ждёт + темы + что знает + что помнит + 6 реплик прошлого разговора); модель недоступна → `pool`.
6. ПОСЛЕ выбора ответа — «нравится / не нравится» по `when` (раз за разговор на пункт).
7. При выдаче ответа персонажа — шанс просьбы (`OfferChance` 0,35 после 2 реплик) или темы (`TopicChance` 0,3 после 1); текст дописывается к ответу.
8. Конец разговора / атака → модель сжимает разговор в 3–5 строк памяти.

## Шкала и фазы

- Счёт от −`scale` до +`scale`, старт 0. Пороги — `PhaseFloor` {−10, −3, 2, 4, 6, 9} × `scale` / 10. Валера `scale 24`: Неприязнь −24…−8 · Знакомство −7…4 · Осторожность 5…9 · Доверие 10…13 · Близость 14…21 · Дружба 22…24.
- Рост за игровой день ≤ `dayGain` (Валера 6): день 1 — максимум «Осторожность», «Дружба» — не раньше дня 4. Минусы без предела.
- Каждая смена — строка истории: день, время, `±N → счёт`, фаза, причина (F1, новое сверху).

## Правила уровня для общения (блок существа)

```
[valera_1][08:00-19:00][talk limit 60s][loop]:
1. … маршрут и работа …

- [player around 6m][chance 25%]:
  [go][player]
  [talk]

- [sees player enter kiosk_zone][if peaceful]:
  (alert 1s)
  [go][player]
  [talk #kiosk_no]
  [attitude -4 залез в ларёк]

- [sees player enter kiosk_zone][if hostile]:
  [go][player][run]

- [sees player examining kiosk_register][if peaceful]:
  [shout #till_away 4s]
  [attitude -4 полез в кассу]

- [sees player examining safe][if peaceful]:
  [go][player]
  [talk #safe_hands]
  [attitude -3 полез к сейфу]

[valera_1][19:00-08:00][no talk][loop]:
1. …
```

- `[player around Nm]` (`герой поблизости N м`, по умолчанию 6) — герой рядом N м, существо его видит ≥ 5 с (`AroundSeconds`) и никто не разговаривает; раз за подход, взводится снова, когда герой отошёл дальше N+2 м.
- `[sees player enter <зона>]` (`видит, как герой вошёл в <зона>`) — герой вошёл в зону, а существо его видит.
- `[sees player examining <объект>]` (`видит, как герой осматривает <объект>`) — герой открыл осмотр объекта (по слагу `safe_1` или по виду `safe`), существо видит.
- `[talk]` / `[talk «текст»]` (`заговорить`) — начать разговор (своя фраза или случайная из `openers`); если далеко — шаг пропущен «сначала [go][player]»; враждебен или занят — тоже пропуск.
- `[attitude ±N причина]` (`отношение`) — изменить счёт (с пределом дня для плюса).
- `[shout «текст» 4s]` / `[say …]` / `[крикнуть …]` — крикнуть вне разговора: над головой N секунд (без времени — по длине), разговор не начинается, строка «[кричит герою] …» уходит в его журнал.
- Текст в `[talk]`/`[shout]`: `#id` из `lines` файла персонажа (RU/EN и вариант по фазе; неизвестный id — красная строка), или черновик `«ру» | «en»`, или просто текст (тогда один на оба языка).
- Заголовок группы: `[talk limit 40s]` / `[разговор до 2 мин]` — пока идёт группа, говорит не дольше; вышло — говорит фразу `leave` по фазе и уходит, до смены группы «занят» (`busy` по фазе). `[no talk]` / `[не разговаривает]` — вообще не говорит.
- Враждебный — ветка `[if hostile]` (атака), мирный — `[if peaceful]` (поругаться, `[attitude -N]`).

## Как добавить персонажа

1. `Dialogs/<id>.json` по схеме выше, всё RU+EN; `name.ru` = имя в игре.
2. Существо в уровне `<id>_1`, `[peaceful]` при спавне.
3. Правила общения в блоке существа (пример выше).
4. `python3 ~/.claude/skills/tavern-dashboard/dialogs/sync_from_game.py` → публикация дашборда (скил `tavern-dashboard`).
5. Регресс `tavern-regress/TALK.md`: EditMode-тесты + ручные кейсы в play.

## Очередь

- Поступки, которые игра пока не ловит: касса, тетрадь, комната, лодки — баллы прописаны в `dislikes`, нужны хуки (или правила `[sees player examining]` / `[sees player enter]`).
- Предмет «моющее средство» (`detergent`) в игре не существует — сюжетную просьбу нечем выполнить.
- «Донести мусор до бака», «постоять с ним» — выполнение не передачей, нужна своя проверка.
- Приветствие от фазы не зависит.
- Память живёт в уровне: на другом уровне персонаж героя не помнит.
- Ничего не проверено в play (на 04.11 ночь) — ручные кейсы `TALK.md` ⏳.
