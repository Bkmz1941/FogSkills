## Что видит игрок

1. Появляется на западном краю, вокруг сплошной туман, видна только асфальтовая дорога на восток.
2. Идёт 6 блоков (36 м) прямо, дальше 2–3 отрезка с поворотами, в конце — Т-развилка, обе ветки
   по 2 блока уходят в туман.
3. Когда герой дошёл до 5-го блока пути (~30 м), дорога позади исчезает в тумане — назад некуда.
4. Верная ветка (по маршруту Л-П-Л относительно хода) — шаг в туман за её концом бесшовно
   переносит героя к началу НОВОЙ дороги в другом месте карты (ступень +1).
5. Неверная ветка, разворот, сход с дороги на 2+ клетки — ловушка тумана (`FogTrap`): своя минута
   блужданий, затем она выпускает к началу новой случайной дороги, маршрут с нуля.
6. После трёх верных развилок новая дорога ведёт к восточному краю карты (середина по z) — выход.
   Что там происходит — НЕ сделано (зона `road_exit` была «Сценарий» без действия).

## Как устроено в коде — `Modules/Effects/RoadTrap.cs`

Синглтон сцены как `FogTrap` (`Bootstrap` → `SceneSingleton<RoadTrap>.SpawnEachScene`). Отладочных
ручек в F1 НЕТ: вкладка «Ловушки» (`HudUI.DebugWeather.cs` → `TrapsTab`, регистрация в
`HudUI.Debug.cs` `("traps", "Ловушки", TrapsTab)`) содержит только блоки «Туман», «Лес», «Капкан».

| Что | Символ | Как |
|---|---|---|
| Константы | `LevelSlug="road_trap"`, `EntrySlug="fog_in_road"`, `ExitSlug="fog_out_road"`, `RoadId="env_highway"` | — |
| Настройки (static, без UI) | `Enabled=true`, `Route="LRL"` | менять только кодом |
| Состояние | `Stage`, `Closed`, `Solved => Stage >= Route.Length` | наружу не читается никем |
| Блок | `BlockCells=2` | 2×2 клетки = 6 м; карта = `Width/2 × Height/2` блоков |
| Включение | `Update` | `Enabled && LevelIO.CurrentSlug == road_trap && GridCursor.I && PlayerRef`; иначе `Teardown` |
| Запуск | `Setup` | ищет сетку `GridRole.Ground` и зоны по слагам; нет хоть одной — молча ждёт; сам ставит `fog_in_road.exits += fog_out_road`; первая дорога `Generate((0, H/2), восток, IntroBlocks=6)` |
| Раскладка | `TryLayout` | прямая `straight` блоков → 2–3 отрезка по 2–3 блока с поворотом Л/П → развилка `Branch` влево и вправо по `BranchBlocks=2`; `goDir` = ветка по `Route[Stage]`, `goBlock` = 3-й блок за развилкой (уже в тумане) |
| Без самокасаний | `Free`, `Inside` | соседи блока не заняты; отступ 1 блок от края (кроме старта у края) |
| Попытки | `Tries=400` | на `Generate` и на внешний цикл в `Advance`/`Reset` |
| Закрытие позади | `CloseBehind` | индекс блока героя в `path` ≥ `CloseAfterBlocks=5` → всё до `at-1` срезается, у нового первого блока тупик назад в туман; `Closed=true` (один раз за дорогу) |
| Верный шаг | `Advance` | герой в `goBlock` → `Stage++`, новая раскладка от `StartFor(heading)` (1 блок от края, по ходу), `Warp` на смещение «к началу новой дороги» |
| Финал | `ToExit` | при `Solved` вместо развилки BFS до блока `(W-1, H/2)` + обрыв дороги на восток за край |
| Сброс | `Reset` | на фронте `FogTrap.Trapped` → `Stage=0`, случайное направление, новая дорога |
| Куски дороги | `SpawnPieces` | `env_highway` (`FurnitureCatalog.Highway`), ширина `RoadWidth=5.5`, сквозь блок — 6 м, тупик/угол/Т — половинки 5,75 м; высота `_groundY - 0.1` (земля в центре блока (0,0), рельеф не учитывается) |
| Туман | `Apply` → `SpawnFogSome` | `env_fog` сильный (`FogView.Def(true)`) на КАЖДУЮ клетку сетки кроме дороги, по `FogPerFrame=60` за кадр, от дальних к ближним; клетки под новой дорогой чистятся `FogView.ClearCell` |
| Зоны | `SetZones` | `fog_in_road.SetCells` = клетки на расстоянии ≥2 (Чебышёв) от дороги; `fog_out_road.SetCells` = клетки блока позади старта, вплотную к дороге |
| Перенос | `Warp` | `CharacterController` off/on, `CameraFollow.Shift`, `CharacterAvatar.Shift`, `FarRadius.WakeAll/ShowNear` |
| Не в сейв | всё спавненное | `LevelIO.Unsaved.Add` — куски и туман в файл не попадают |
| Лог | `Debug.Log("[RoadTrap] …")` | «ловушка дорог: W×H блоков», «дорога назад закрылась», «верный поворот, шаг N/3», «маршрут пройден», «туман: маршрут сначала», «не уложил дорогу» |

Связь с ловушкой тумана: `RoadTrap` её не трогает. `FogTrap` (`Modules/Effects/FogTrap.cs`) видит
`fog_in_road` как обычную зону `FogEntry`, держит `ExitSeconds` (по умолчанию 60 с, ползунок
«Выход» во вкладке «Ловушки») и выпускает в связанную `FogExit` — её клетки `RoadTrap` всегда держит
у начала текущей дороги. Пока `FogTrap.Trapped`, `RoadTrap.Update` ничего не делает.

## Данные в файле уровня

`RoadTrap` ничего не читает из файла, кроме слага уровня и двух зон по слагам; дорога, туман и
клетки зон строятся в play. Минимум (как было 17.10 в «Ловушка дорог.json», 30×30, начало −43,5):

| Что | Значение |
|---|---|
| `slug` | `road_trap` (ровно так) |
| Сетка земли | любая; блоков = `gridWidth/2 × gridHeight/2` |
| Маркер спавна | объект `spawn_marker` (`SpawnPoint.ObjectId`) в центре стартового блока `(0, H/2)`: x = `gridOriginX + 1.5`, z = `gridOriginZ + (2·⌊H/2⌋ + 0.5)·3`, где H = `gridHeight/2` (17.10: (−42; 0) при начале −43,5) |
| Зона `fog_in_road` | `kind: 8` (FogEntry), `exits: "fog_out_road"`, клетки любые (перезапишутся) |
| Зона `fog_out_road` | `kind: 9` (FogExit), клетки любые |
| Зона выхода (опц.) | 17.10: `road_exit` «Выход из ловушки», Сценарий (`kind: 1`), клетки 28–29 × 14–15. Код её не знает; чтобы вела куда-то — Переход `kind: 20`, слаг `to_<слаг>` (tavern-offscreen) |

Клетка зоны в JSON — центр в мире: `{"x": ox + i·3, "y": 0.1, "z": oz + j·3}` (`gridOriginX/Z` —
центр клетки 0). У зон ещё есть массив `fine` (мелкие клетки) — для этих двух зон можно пустой.

## Как СОЗДАТЬ

**Через игру (предпочтительно, сохраняет сама игра):**
1. Новый уровень, сохранить под именем (например «Ловушка дорог»), слаг в карточке уровня `road_trap`.
2. Стройка → «Шоссе» не ставить: дорогу строит код. Поставить маркер спавна («Спавны») на запад,
   середина по z.
3. Зоны: «Зона входа в туман» (слаг сам станет `fog_in_N` — переименовать в `fog_in_road`),
   «выход из тумана» → слаг `fog_out_road`; в карточке входа отметить выход `fog_out_road`
   (код и сам допишет связь). Клетки — по одной, они перезаписываются.
4. Без построек и растений: туман встанет на каждую свободную клетку всей сетки.
5. Вход с другого уровня — зона Переход `to_road_trap` (OPEN.md: где на шоссе level1 — решает Илья).

**Через JSON** — рецепт ниже (на копии, уровень в редакторе закрыт).

## Как СГЕНЕРИРОВАТЬ / настроить на уровне 100×100

Железное правило: игровой уровень 300×300 м = 100×100 клеток по 3 м. Тогда карта 50×50 блоков,
стартовый блок `(0, 25)` = клетки 0–1 × 50–51, финальный блок `(49, 25)` = клетки 98–99 × 50–51.

```python
import json, shutil, time
P = "/home/ilya/.config/unity3d/DefaultCompany/Tavern/levels/Ловушка дорог.json"   # имя — своё
shutil.copy(P, P + ".bak-before-roadtrap-" + time.strftime("%d%m"))              # ВСЕГДА копия
d = json.load(open(P))
assert d["slug"] == "road_trap" and d["gridWidth"] == 100 and d["gridHeight"] == 100
cs, ox, oz = d["cellSize"], d["gridOriginX"], d["gridOriginZ"]
W, H = d["gridWidth"] // 2, d["gridHeight"] // 2            # блоки
def cell(i, j): return {"x": ox + i*cs, "y": 0.1, "z": oz + j*cs}
def block_cells(bx, by): return [cell(bx*2+a, by*2+b) for a in (0,1) for b in (0,1)]
tpl = next(z for z in d["zones"] if z["kind"] in (8, 9))   # взять полный набор полей у живой зоны
def zone(slug, name, kind, cells, exits=""):
    z = dict(tpl); z.update(slug=slug, name=name, kind=kind, exits=exits, cells=cells,
                            fine=[], marks=[], events=[]); return z
d["zones"] = [z for z in d["zones"] if z["slug"] not in ("fog_in_road", "fog_out_road", "road_exit")]
d["zones"] += [zone("fog_in_road", "Туман ловушки дорог", 8, [cell(5, 5)], "fog_out_road"),
               zone("fog_out_road", "Туман отдаёт к дороге", 9, [cell(5, 7)]),
               zone("road_exit", "Выход из ловушки", 1, block_cells(W-1, H//2))]
# спавн: центр стартового блока (0, H//2) — двигаем уже стоящий spawn_marker (ставится в игре, «Спавны»)
sx, sz = ox + 0.5*cs, oz + (2*(H//2) + 0.5)*cs
sp = [o for o in d["objects"] if o["id"] == "spawn_marker"]
assert len(sp) == 1, "маркер спавна поставить в игре"
sp[0]["pos"].update(x=sx, z=sz)
json.dump(d, open(P, "w"), ensure_ascii=False)
print("spawn at", sx, sz)
```
Шаблон зоны берётся из уже существующей зоны, иначе в файле может не хватить полей (объект
`spawn_marker` — ~90 полей, руками не собирать). Если зон 8/9 в файле нет — взять
шаблон из «Лес (тест).json». Без Unity-моста цифры зон не проверить — после записи открыть уровень
в игре и посмотреть зоны («показывать зоны» в дебаге).

Маршрут и размеры — только кодом (`Route`, `IntroBlocks`, `CloseAfterBlocks`, `BranchBlocks`,
`BlockCells`); правка кода — по tavern-refactor/tavern-regress.

## Как УДАЛИТЬ чисто

2. Из `zones` убрать `fog_in_road`, `fog_out_road`, `road_exit` (и `to_road_trap` на уровне-входе).

## Грабли

- **Слаг зашит.** `LevelSlug = "road_trap"`; на level1/level2 ловушка не включится. Ставить её
  кусочком большого уровня нельзя без переделки: туман и зоны покрывают ВСЮ сетку, `ToExit`/старт
  считаются от краёв сетки.
- **Нет зоны — тишина.** Без `fog_in_road`/`fog_out_road` или сетки `Ground` `Setup` молча
  возвращает false каждый кадр — ни лога, ни ошибки.
- **Пересохранение в play.** Клетки зон `SetCells` меняются в play; зоны не в `Unsaved` —
  сохранение уровня в play (вероятно) запишет текущие сгенерированные клетки. Не сохранять уровень
  внутри ловушки.
- **Рельеф.** Высота дороги и тумана — одна (`GroundY` в центре блока (0,0)); уровень должен быть
  плоским, иначе дорога утонет/повиснет.
- **Постройки и растения** на сетке туман обходит только по `FogView.Occupied`; на пустом уровне
  проблем нет, на обжитом туман/дорога лягут сквозь объекты.
- **Клетки зон руками в игре** — только `ZonePiece.RemoveCell`/`SetCells`, не правкой `Cells`
  (DESIGN_LOG 17.10, Черное озеро).
- **Всё временное — в `LevelIO.Unsaved`** (PITFALLS P-правило осады вороны) — при правке кода не
  забыть для новых спавнов.
