# Генерация звуков (sfx)

Звуки считаются локально на RTX 3060 Ti (8 ГБ), наружу ничего не уходит,
лимитов нет. Модель — Stable Audio 3 small-sfx (Stability AI, май 2026,
433M параметров), заточена под эффекты и фоли, не под музыку. Заведено
2026-10-06 (Илья: «попробуй поставить»).

**Корень:** `/media/ilya/T714/sfx-gen` (exFAT). Команда `sfx` в PATH через
`~/.local/bin/sfx` → симлинк на `$ROOT/sfx`.

## Команды

```
sfx "промпт" [-d 4] [-n 3] [-o имя] [--seed N] [--steps 8] [--cfg 1.0] [--neg "..."] [--raw]
```

- Результат — `$ROOT/out/<имя>_<seed>.wav` (44,1 кГц, стерео). Повторить
  вариант — тот же `--seed`.
- `-d` — длительность в секундах (до 120). Короткие эффекты 1–5 с, фон 8–30 с.
- `-n 3` — три варианта подряд (seed, seed+1, seed+2); модель грузится один раз.
- Громкость по умолчанию выравнивается до пика −1 дБ: модель отдаёт тихо
  (пики 0,1–0,4). `--raw` — без выравнивания.
- `--steps 8` и `--cfg 1.0` — значения из карточки модели, менять незачем.
- Старт модели ~13 с, звук 4 с — 1–5 с, если видеокарта свободна (8 с фона
  при занятой карте — до 17 с). Процесс один на вызов: отработал и отдал память.

## Промпты

Короткое предметное описание по-английски: **что звучит + на чём/где + как**.
Работают конкретные слова, а не настроение:

| Нужно | Промпт |
|---|---|
| скрип двери | `old wooden door slowly creaking open in an empty house` |
| шаги по дому | `footsteps on creaky wooden floorboards, slow, indoors` |
| ворона | `a single crow cawing loudly in a misty forest` |
| гул тумана | `low ominous droning wind ambience, eerie fog, horror` |

- `indoors` / `in a small room` / `distant` / `close-up` заметно меняют
  пространство — указывать всегда.
- Один звук — один промпт. «Дверь, потом шаги, потом крик» модель смешает.
- Лишнее (музыка, голоса, щебет на фоне) — в `--neg "music, speech, birds"`.
- Проверять ушами Ильи: сессия звук не слышит. Для своей грубой проверки —
  спектрограмма (numpy + PIL, по образцу в истории 06.10): у удачной вороны
  видны отдельные «кар» с гармониками, у шагов — ровные удары.

## ⭐ «Звук как из трубы» — узкая полоса, лечится промптом + `brighten.py` (06.10)

Илья 06.10 про ворону: «будто из трубы звук, надо улучшить». Замер: у small-sfx 80–95 % энергии крика в
полосе 1–2 кГц, выше 4 кГц почти пусто (у настоящей вороны в игре, `Sounds/crow_caw.wav`, 2–8 кГц — 22 %).
Узкая полоса без верхов и есть «труба».

1. **Промпт:** хрип и сухость словами + запрет глухого.
   `raven and crow caw in an autumn forest, harsh noisy throaty cry, crisp high fidelity, close microphone`,
   `hooded crow croaking aggressively, harsh guttural kraa kraa, bright detailed sound, nature field recording, 48kHz`;
   `--neg "music, speech, other birds, muffled, lo-fi, telephone, tube, pipe, reverb, echo, low quality"`.
   Это поднимает верхи с 5–9 % до 12–18 %. «dry close-up … full frequency» и «carrion crow … crisp» не помогли (3–6 %).
2. **Генерировать с запасом и мерить:** 4 промпта × 4 зерна, сортировка по доле 2–8 кГц в громких кадрах.
3. **`$ROOT/brighten.py src dst [src dst …]`** (Python венва): срез ниже 150 Гц; «эксайтер» — tanh верхней
   части (>1,4 кГц) даёт хриплые обертоны, их выше 2,8 кГц подмешать; полка +2…4 дБ выше 3,2 кГц.
   Сила подбирается сама под 28 % верхов (больше — шипит: при 37–47 % проверено, перебор), хвост тишины
   обрезается с затуханием 50 мс, пик −1 дБ.
   `.venv/bin/python brighten.py out/a.wav out/a_final.wav`

## ⭐ В `out/` — только актуальное (Илья 07.10: «не копи звуки, удаляй старые варианты», «оставляй только актуальный»)

- Новый раунд вариантов ЗАМЕНЯЕТ прошлый: старые варианты и их отбракованные кандидаты — сразу в корзину
  (`gio trash`), не копить рядом «на сравнение».
- Илья выбрал — остаётся ОДИН файл (и исходники, без которых его не пересобрать); остальное в корзину.
- Ушло в игру — копию в `out/` не держать: эталон теперь лежит в `Assets/Resources/Sounds/`.
- Рецепты сведения (`*.py`) держать, если по ним пересобирается актуальный звук.

## Куда класть в игру

- Черновики живут в `$ROOT/out/`. Илья выбирает → файл копируется в
  `Assets/Resources/Sounds/<имя>.wav` проекта (там лежат `crow_caw.wav`,
  `door_open.wav`, `owl_hoot.wav` и др.), грузится
  `Resources.Load<AudioClip>("Sounds/<имя>")`, играется через `GameSfx`.
- Петли (фон, гул) — только WAV/OGG, не MP3: MP3 в Unity длиннее своего
  звука на набивку кодировщика, петля запинается (P640).
- Правила слышимости и приглушения по этажам — область «звук» в
  `bugs.py звук` (tavern-regress).

## Видеокарта общая

Модель держит ~2,4 ГБ VRAM на время вызова. Рядом могут сидеть редактор Unity
(2–4 ГБ), ComfyUI от `ig` (см. image-gen, `ig --stop`) и Ollama
(tavern-ai-chat, ~5,5 ГБ). Если `sfx` падает по памяти — проверить
`nvidia-smi`; чужую модель не выгружать самому, а попросить её сессию.

## Устройство

- `$ROOT/src` — клон `Stability-AI/stable-audio-3` (pip install -e).
- `$ROOT/.venv` — Python 3.12, torch 2.7.1+cu126. Венв на exFAT создаётся
  только так: `mkdir -p .venv/lib64 && python3 -m venv --copies .venv`
  (иначе падает на симлинке `lib64`); ставить `pip --no-cache-dir`, uv на
  exFAT ломается на симлинках своего кэша.
- `$ROOT/models/small-sfx` — веса (3,3 ГБ): модель + текстовый энкодер
  T5Gemma. Официальный репо HF закрыт (нужен токен и принятие лицензии),
  взято открытое зеркало `cocktailpeanut/stable-audio-3-small-sfx`
  (safetensors). `gen.py` грузит всё из этой папки, в сеть не ходит
  (`HF_HUB_OFFLINE=1`).
- `$ROOT/gen.py` — обёртка; `$ROOT/sfx` — лаунчер (TMPDIR и HF_HOME внутри корня).
- Лицензия — Stability AI Community License: бесплатно при выручке до
  1 млн $ в год.
