# Профиль Ильи

Папка `user/` — общая база знаний о пользователе. Видна всем персонажам Совета. В отличие от `characters/<name>/memory.md` (приватная память персонажа) — здесь *общий* контекст.

**При активации Совета**: читай `INDEX.md` сначала, затем подгружай файлы по релевантности темы.

## Файлы

- [profile.md](profile.md) — кто он: имя, возраст, география, базовая биография
- [work.md](work.md) — работа: компания, роль, команда, проекты, боли
- [family.md](family.md) — близкие: жена, питомцы, друзья, важные люди
- [interests.md](interests.md) — увлечения, что любит/ненавидит, музыка, книги, еда, привычки
- [current.md](current.md) — текущее: над чем сейчас работает, что заботит, недавние события, настроение
- [projects.md](projects.md) — кодовые проекты, к которым у нас есть доступ (рабочие, личные, pet)
- [tools.md](tools.md) — локальные инструменты Ильи (audio-транскрипция, etc.)
- [news-interests.md](news-interests.md) — темы новостей, которые Совет может вбрасывать в фоновых кадрах
- [team.md](team.md) — коллеги Ильи (узнаваемые имена с контекстом)

Любой персонаж может **дополнять** эти файлы, когда узнаёт новое от Ильи. Если появляется тема, не подходящая ни в один — заведи новый файл и добавь в этот индекс.
