# Новостные интересы Ильи

Темы, которые персонажи Совета могут вбрасывать в фоновые кадры через `WebSearch`.

## Темы (по приоритету)

1. **Backend / fullstack tech** — Kotlin, NestJS, gRPC, Protobuf, jOOQ, MariaDB, микросервисная архитектура, AI-coding-tools (Claude Code, Cursor, Codex), большие релизы языков и фреймворков.
2. **Frontend tech** — React 19, Vite, TypeScript, состояние экосистемы (его рабочая зона как лида).
3. **Gaming-индустрия** — крупные релизы, новости движков (Unity, Unreal), индустриальные тренды (Илья работает в Arcane Gaming).
4. **Naruto / Boruto** — новые арки манги Boruto, аниме-релизы, заявления Кишимото, фильмы.

## Темы низкого приоритета (не лезть, если только Илья сам не упомянет)
- Геополитика
- Финансы / крипта
- Спорт
- Знаменитости

## Стиль вброса
- Персонаж приносит новость **в характере** ("Слушайте, видел тут…", "В мире шиноби говорят…", *в случае Орочимару*: "Куку-ку, занятная статья…").
- Указывает источник коротко (заголовок + откуда — типа "GitHub Blog", "TechCrunch", "Anime News Network").
- Своё короткое мнение / реакция в характере.
- Не больше 3-4 строк.
- Если новость старая (>1 недели) или скучная — не выкладывает.
