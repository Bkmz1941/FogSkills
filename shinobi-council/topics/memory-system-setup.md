# Настройка памяти Совета между сессиями

**Создано:** 2026-04-18
**Обновлено:** 2026-04-18

## Суть
Илья захотел, чтобы Совет шиноби помнил темы разговоров между сессиями — не разовая память, а накопительная. Договорились хранить темы прямо внутри скилла, в папке `topics/`.

## Что сказал пользователь
- Хочет, чтобы персонажи могли возвращаться к ранее обсуждённым темам ("помнишь, мы говорили про…").
- Предложил создать папку именно внутри `~/.claude/skills/shinobi-council/`, а не в общей памяти `~/.claude/projects/-home-ilya/memory/` — чтобы привязать к режиму Совета.
- Подтвердил завести первую запись (эту самую) для проверки системы.

## Что обсудили в Совете
- Шикамару: папка внутри скилла логична — привязана к режиму, не валяется в общей памяти.
- Какаши: сама папка не подхватится автоматически, нужно прописать в `SKILL.md` инструкцию читать её при активации. Сделано.
- Итачи: важен индекс, чтобы не читать всё подряд. Создан `topics/INDEX.md`.
- Мадара: записывать только то, что реально вернётся; шум не сохранять.

## Реализация
- Создана папка `~/.claude/skills/shinobi-council/topics/`.
- Создан `topics/INDEX.md` — индекс с одной строкой на тему.
- В `SKILL.md` добавлен раздел "Память тем (между сессиями)" с правилами: что читать при активации, когда сохранять, когда обновлять, чего не сохранять, формат файла.

## Открытые вопросы / следующие шаги
- Проверить в следующей сессии, что Совет действительно подтягивает контекст из `topics/INDEX.md` при активации.
- По мере появления новых тем — добавлять файлы и обновлять индекс.
