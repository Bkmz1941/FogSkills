# Персонажи — модели людей, вид и анимации

Заведён 2026-10-16 по слову Ильи: «у нас есть скил по работе с моделями и одеждой персонажей? создай если нет и всегда
его используй, в нём опиши всё, что существует, от вида до анимаций». Это ВХОД: что есть, где лежит, как собирать.
Глубокие подробности живут в доменных файлах — здесь ссылки, а не копии (одна правда в одном месте).

## ⭐⭐ Правила — действуют всегда

1. **Один скелет на всех людей** — KI `B-*`, 56 костей (парень, девушка, сектант, пропавшие). Поэтому любой клип и любая
   вещь по именам костей ложатся на любого без ретаргета. Новое тело — только на этом скелете.
2. **Blender — эталон, сначала только Blender** (`tavern-game/BLENDER.md`, правило 1). В игру — по слову Ильи
   «переноси / в игру».
3. **Вид человека собирается из игровых ресурсов**, если вещь уже есть в игре: тело `Models/HumanCharacterDummy_{M,F}_Skin`,
   вещи `Resources/Clothes`, волосы генератором `hair_scene.py`. Тогда модель поедет в игру без переделки. Новая вещь —
   из тела (скил `tavern-clothes`, правило 1), не накладкой.
4. **Смотреть парой**: Т-поза — правим, стойка и ходьба — судим (`tavern-clothes`, правило 2). Человек в кадре — в позе
   покоя `Idle01`.
5. **Анимация с руками — только по ЗАКОНУ АНАТОМИИ РУКИ** (`tavern-game/CHARACTER.md`), судить замером по кадрам.
6. **Мерка — персонаж 2,55 м в игре** (`tavern-game/BLENDER.md`, правило 8); в Blender тела в своих метрах (~1,83 / 1,77).
7. **Картинки Илье не шлём** — смотрит в открытом окне Blender; окно сохраняем в режиме материалов (цвет волос — в
   цвете вершин, в «Solid» он белый: у материалов причёсок задавать `diffuse_color`, 16.10).
8. **Лиц нет** — манекен KI гладкий, это стиль (листовки тоже без лиц). Черты читаются причёской, бородой, очками, одеждой.
9. **Новое существующее — сразу строкой в `CATALOG.md`** (что, где, в игре или только Blender, дата). Скил описывает
   ВСЁ, что есть; устарело — пометить, не держать молча.

## Как начинать задачу про человека

1. `tavern-game/SKILL.md` (мост, play) → этот файл → `CATALOG.md` (что уже есть — не делать заново).
2. По теме — доменный скил из карты выше; одежда — `tavern-clothes/BLENDER.md`, клип — `CHARACTER.md` «Анимации».
3. Грабли: `python3 ~/.claude/skills/tavern-regress/probes/bugs.py персонаж`, `… анимация`, `… блендер`.
