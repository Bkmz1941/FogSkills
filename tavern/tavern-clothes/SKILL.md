# Одежда «Таверны» — скил домена

Скил-память ТОЛЬКО по одежде: от блендеровской нарезки тела до плитки в
инвентаре. Общие правила проекта (MakeRoom-стиль, Blender — эталон, KISS,
никаких комментариев-объяснялок в коде, «новое работает на старом контенте»,
проверка Unity MCP в начале сессии, не компилировать в play) — в
`tavern-game/SKILL.md`; **читать его первым**, этот — вторым. Общий
блендер-пайплайн (два пайплайна, мост MCP, перенос объекта 1:1, `blender_kit`,
`pipeline.py`) — `tavern-game/BLENDER.md`.

обновить `CLOTHES.md`/`BLENDER.md` (там только актуальное). Кросс-доменное
(новый UI-экран, новый атрибут дефа) — короткой ссылкой в
`tavern-game/DESIGN_LOG.md`.

## ⭐⭐ Три правила, которые дороже всего стоили

1. **Одежда делается ИЗ ТЕЛА, а не поверх него.** Кусок кожи копируется и
   отодвигается наружу — поэтому ткань сидит по фигуре и кожа не просвечивает.
   Накладки «сверху» отвергнуты (`BLENDER.md`, «Нарезка тела на зоны»).
2. **Одежду всегда смотрим ПАРОЙ** (Илья 04.09: «с одеждой используй в паре
   всегда ещё то, как он стоит в расслабленной анимации»). Т-поза — правим,
   стойка и ходьба — судим. Половина дефектов видна только на живой позе.
3. **Вещь одежды делается СРАЗУ ВМЕСТЕ с объектом мира «как лежит»** (Илья
   05.09). Без сложенной вещи на полу вещь не считается сделанной: в игре она
   и на герое, и на полу.

## ⚠️ САМОЕ ОПАСНОЕ МЕСТО ДОМЕНА

`human_skin_cut.py` запущенный целиком (`run()` / `blender -P human_skin_cut.py`)
**открывает файл ТЕЛА и пересобирает файл ОДЕЖДЫ с нуля**: `clear_old()` сносит
всё, в чьём имени есть `_Cut`, а `run()` строит только нарезку + джинсы. Всё
остальное — футболки (белая, бежевая, красная), кроссовки, тапочки, домашние
штаны, объекты `JV1/JT1/JT2/JT3/JH1/SH1/SH2/SH3` и ручные правки Ильи —
существует ТОЛЬКО в `Library/humanClothes.blend` и будет потеряно. Раннеры,
которыми их когда-то собирали (`shirt_variant.py`, `jeans_new_pants.py`,
`slippers_build.py`), жили в скретчпадах сессий и не сохранились.

Значит: **файл `humanClothes.blend` — источник истины, а не скрипт.** Правки
делаются точечными вызовами функций на живом файле
(`import human_skin_cut as m; m.make_shoes(...)`), файл вне git, откат — только
из `.blend1` или своей копии в скретчпаде. Перед рискованной правкой — снимок.

## Как начинать сессию по одежде

1. `tavern-game/SKILL.md` → проверка Unity MCP → этот файл → `CLOTHES.md`.
2. Задача в Blender — ещё `BLENDER.md` здесь и `tavern-game/BLENDER.md`
   (мост, правило «правки смотрим в открытом окне», ⚠️ второе окно забирает
   порт 9876 — P264).
3. Задача про UI (слоты, кукла, драг) — `tavern-game/UI.md` обязателен.
4. Перед правкой — брифинг по граблям:
   `python3 ~/.claude/skills/tavern-regress/probes/bugs.py блендер` и
   `… перенос`; после — `check_all.py`.
5. Проверки одежды (три пробы) — в `CLOTHES.md`, раздел «Чем защищено».
