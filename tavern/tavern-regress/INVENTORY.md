# Инвентарь и окно «Предмет»: регресс по группам

⭐ Подгруппа «инвентарь» (Илья 20.10: «сделай для регреса подгруппу — Инвентарь и попап осмотра объекта и придумай все тесты для них, объединим»). До 20.10 окно «Предмет» жило отдельным набором `INSPECT.md` (Илья 18.10), фигура игрока — только в пробе `inventory_doll_probe.cs`. Теперь одна подгруппа: область `инвентарь` в `bugs.py`, коды IN-… (окно «Предмет»), INV-D… (фигура игрока), INV-… (остальное окно).

Что сюда входит: окно инвентаря целиком — фигура игрока, сетки (свой инвентарь, руки, экипировка, чужой контейнер), перетаскивание, меню предмета, режим выбора, вес, хотбар — и модал «Предмет» (`InventoryScreenUI.OpenInspect`). Фигура и «Предмет» — один стенд `ItemPreview3D`; снимки иконок (`Snapshot`) идут через него же. Состояние — `tavern-game/UI.md` («Окно «Предмет»», «Сетка инвентаря»), вес — скил `tavern-player`, одежда в слотах — `CLOTHING.md`, продукты в инвентаре — `PRODUCTS.md` (здесь на них только ссылки).

## Главные правила стенда (крит Ильи)

1. **Камера и сетка не двигаются никогда** (18.10, 20.10 «сетка не должна двигаться никогда»). Поворот, колесо, подъём средней кнопкой, «вид по умолчанию» двигают МОДЕЛЬ.
2. **Модель никогда не касается сетки и не уходит в неё** (20.10, скрины 02-50-00 «Ключ» и 02-51-53 фигура: «прям никогда никогда»). Ни на старте, ни при повороте стрелками и мышью, ни при колесе, ни при сдвиге, ни при самом малом отступе ручки (1,0). Зазор не меньше `GridClear` (2 % нижней точки).
3. **Модель не режется кадром снизу**: ноги фигуры и низ предмета всегда в кадре.

## Правила набора

1. **Проба идёт по ВСЕМ предметам по признаку**: `FurnitureCatalog.All()` с `pickupItemId`. Новый предмет попадает под все кейсы сам.
2. **Проба повторяет настоящее окно**: тот же порядок вызовов, что `InventoryScreenUI.ApplyInspectLook` (`FitInside` с отступами стрелок → `SetGrid`), самая строгая ручка (отступ 1,0). 20.10: проба без `FitInside` держала пол на радиусе сферы и была зелёной при красном в игре (P1157).
3. **Стенд пробы свой**: держатель вне канваса, `DestroyImmediate` после каждого предмета. Окно у Ильи не открывается, уровень не меняется — любой уровень.
4. **Не больше 100 стендов за вызов** — дальше проба режет себя и пишет «НЕПОЛНОЕ» (P1158: целиком по 299 предметам уронила редактор в драйвере NVIDIA). Гонять через `check_all.py` (частями по 4).
5. **Мерить настоящей геометрией**: углы `mesh.bounds` каждой детали через её `localToWorld`, не `Renderer.bounds`.
6. **Починка = красная проба на старом коде → правка → перезаход → зелёная.** Мутация обязана краснеть: `_keepInFrame = false`, `_zoomMin` 0,12, сетка-ребёнок камеры, `Rotate` без `PlaceCamera`.
7. **Решение Ильи меняет ожидание — сразу переписать кейс** (19.10 «фигура опускается вместе с сеткой» → 20.10 «сетка не двигается никогда» + «никогда не в сетке»: INV-D08 переписан).

## Когда гонять

ДО и ПОСЛЕ правки любого из путей:
- `Assets/Game/UI/Screens/ItemPreview3D.cs` (стенд, камера, свет, сетка, поворот, сдвиг);
- `InventoryScreenUI*.cs` — `Build` (фигура, `SetGrid`), `Actions` (`OpenInspect`, `ApplyInspectLook`, меню, режим выбора), `Drag` (перетаскивание, рамка), `Craft`;
- `HudUI.DebugCraft` / `DebugPopups` (блоки «Блок игрока», «Предмет», «Сетка пола»);
- `GridInventory`, `Equipment`, `Carry`;
- `UiFactory.Chevron` / `IconButton`, `UiIcons`;
- `FurnitureModel.MakeSizedModel` / `Combined`, экспорт модели предмета из Blender.

Команда: `python3 ~/.claude/skills/tavern-regress/probes/check_all.py` (в play). Отдельно: `inventory_doll_probe.cs` целиком через `tavern-night/ex.py`; `inspect_window_probe.cs` — только частями.

Обозначения: ✅ — проба есть и зелёная, ⏳ — проверено руками или ждёт play, 🆕 — кейс без пробы.
