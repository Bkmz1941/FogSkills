# Проверки: что запускать и чего ждать

Каталог самих зондов — `probes/README.md`. Здесь только «чем гонять, сколько
это стоит и что мешает».

## Один прогон всего: `check_all.py` (19 секунд)

```
python3 ~/.claude/skills/tavern-regress/probes/check_all.py
```

Линт граблей → офлайн-компиляция → тесты EditMode (если редактор свободен) →
живые пробы (если в play). Печатает вердикт и что именно красное. Это
**единственная команда, которую надо помнить после правки**.

⚠️ **Красный сразу после сессии в play — сначала перекомпиляция, потом
разбор** (P269). Статические кэши переживают выход из play и держат
уничтоженные Unity объекты; `KitMaterialsTests` из-за этого падает с «слоты не
прочитались: 0», хотя код не менялся. `cycle.py compile` чистит домен, и
прогон становится зелёным. Обратное тоже верно: зелёный прогон сразу после
компиляции ничего не говорит о поведении после часа в play.

## Брифинг и линт граблей: `bugs.py` (секунда, без Unity)

```
bugs.py                 области и счётчики
bugs.py наведение       брифинг по области: инварианты, правила, чем проверять
bugs.py P044            запись целиком
bugs.py --lint          формат и ссылки
```

Читает `tavern-game/PITFALLS.md` и `INVARIANTS.md`. Линт краснеет на дублях
номеров, неизвестных областях, записях без симптома, причины или правила и на
инвариантах со ссылкой на несуществующую запись; предупреждает о записях без
«Решение» и «Защита».

## EditMode-тесты (132 штуки)

Данные, каталог, модели, атрибуты, рецепты, локализация: битые ссылки, ноды
дефов, бюджет треугольников, достижимость раскладок, составные коллайдеры,
порядок строк в панели объекта, переводы.

```
run_tests {"mode":"EditMode"}                    старт, вернёт job_id
get_test_job {"job_id":"…","include_failed_tests":true}
```

- ⚠️ **В play не стартуют.** «Cannot start a test run while the Editor is in or
  entering Play Mode» — не поломка, а занятый редактор.
- ⚠️ **Пока идёт play, Unity ОТКЛАДЫВАЕТ компиляцию:** свежие правки в тестах
  не участвуют. Проверять `EditorApplication.isCompiling`.
- ⚠️ Два теста ловят не код, а дисциплину: **порядок строк в панели объекта**
  (новый флаг в `ObjectAttributes.Flags` обязан быть подтверждён в тесте) и
  **локализацию** (каждая русская строка кода переведена). Новый флаг роняет
  ОБА разом — это норма, а не поломка.

## Офлайн-компиляция (5 секунд, без Unity)

```
python3 compile_check.py
```

Roslyn по всем сборкам, быстрее, чем ждать редактор. ⚠️ Скрипт берёт проект из
ТЕКУЩЕЙ папки (`os.getcwd()`): запуск откуда-то ещё молча собирает не то и
оставляет мусорный `Temp/compile_check`. Пачка `CS0006` — две сессии запустили
одновременно, повторить (P009).

## Цикл правки: `cycle.py`

```
python3 cycle.py compile          refresh + компиляция, ждать готовности, показать ошибки
python3 cycle.py all [уровень]    stop → compile → tests → play → пробы
```

## Кисть багов (Илья рисует, сессия читает)

Дебаг-меню, вкладка «Вид», строка с иконкой жука: левая кнопка ставит точки по
поверхностям, правая снимает последнюю. Отметки уезжают в `BugMarks.json` рядом
с проектом вместе с id объекта и именем узла под точкой. Сессия читает файл
напрямую — область бага приходит в машинном виде (первый случай: провал
предметов внутрь угловой тумбы нашёлся за один замер, P067).

## Чего в наборе НЕТ

Честно, чтобы не считать себя прикрытым:

- **цены кадра** — ни одного автоматического порога по вызовам отрисовки или
  треугольникам; всё меряется руками и только когда кто-то вспомнит;
- **Always Included Shaders** — проверяется только прод-сборкой, и терялось
  дважды (P015, дождь 07.09);
- **переноса предмета** дальше видимости носимого — три бага за сутки (P079)
  и ни одной автопроверки;
- **одежды в play**, кроме джинсов — зонды футболок и тапочек не сохранены
  файлами.

Полная карта дыр — `COVERAGE.md`.
