# Сектант «Таверны» — скил домена

Скил-память ТОЛЬКО про сектанта: от тела героя в Blender до монстра в игре.
Общие правила проекта (MakeRoom-якорь, KISS, никаких комментариев в коде,
«новое работает на старом контенте», проверка Unity MCP в начале сессии, не
компилировать в play) — в `tavern-game/SKILL.md`, **читать его первым**.
Правила домена существ (темп угрозы, порода дефом, гейт этажом, замирание вне
кадра) — `tavern-monsters/SKILL.md`, **читать вторым**; этот — третьим.

Заведён 2026-10-07 по слову Ильи: «давай начнем делать персонажа "сектант", он
человек, двигается как человек, пока модельку создай и скил для монстра
такого». Начало работы — 14.09 (запись в `DESIGN_LOG.md` здесь), тогда домен
жил разделом 15 в `tavern-monsters/MONSTERS.md`; с 07.10 он целиком здесь.

Имена: в разговоре и скиле — **сектант** (Илья 07.10; 14.09 в скиле писали
«культист», это то же лицо). Файлы — `sectant_*`, модель — `sectant.blend`.

## ⭐ Правила домена — действуют всегда

1. **Сектант — человек и двигается как человек** (Илья 07.10). Тело героя, риг
   KI `B-*` (56 костей), значит игровые клипы, Humanoid-аватар и вещи по
   именам костей работают без ретаргета. Свои клипы — слоем поверх клипов
   героя или с нуля по `tavern-game/CHARACTER.md`, «Принципы работы с моделью
   персонажа», п. 4; перед любой анимацией с руками — «ЗАКОН АНАТОМИИ РУКИ» там же.
2. **Порядок, который задал Илья 14.09: модель → свои анимации (стоит, ходит,
   бежит) → игра.** Сначала ТОЛЬКО Blender (правило 1 `tavern-game/BLENDER.md`):
   ни экспорта, ни дефа, ни кода, пока Илья не сказал «переноси».
3. **Файл монстра свой, исходник героя не трогается.** `sectant_build.py`
   открывает `Library/humanSkin.blend` и сразу `save_as` в `Library/sectant.blend`.
   Истина по форме — скрипт, `.blend` — результат сборки: руками в нём ничего
   не хранить, правка = число в `P` + пересборка (как у девушки). Файл вне git
   (`[Ll]ibrary/` в `.gitignore`) — перед рискованной пересборкой снимок в
   скретчпад сессии.
4. **Вид (Илья 07.10): чёрный сектантский балахон с широким подолом до пола,
   верёвка вместо пояса с узлом, на голове глубокий капюшон.** Один вариант,
   его улучшаем («оставляй 1 вариант, черный, другие удали, будем улучшать
   его»). Снято Ильёй и в скриптах не живёт: брюки со стрелками и строгая
   рубашка 14.09 («удали старые варианты»), роба 14.09, рваные джинсы.
5. **Балахон строится ВОКРУГ тела по его меркам, а не «из тела».** Свободная
   вещь не повторяет кожу: кольца по срезам тела с припуском, рукава трубами по
   оси руки, капюшон кольцами вокруг головы (`sectant_robes_build.py`). Веса у
   кокетки, капора и рукавов — явные кости, не «с ближайшей вершины кожи»
   (P978). Правило `tavern-clothes` «из тела» остаётся для облегающих вещей.
6. **Порода задаётся дефом** (правило 2 `tavern-monsters`): в игре сектанта
   оживляет общий мозг `CreaturePlan` и ядро `Creature` (безумец и его класс
   `Monster` удалены 11.10); отдельный класс — только по решению Ильи.
7. **Мерка — ПЕРСОНАЖ 2.55 м**, опорные высоты по костям в правиле 8
   `tavern-game/BLENDER.md`; одежда и позы судятся на ходячей и бегущей копии,
   а не только на позе покоя (правило «смотрим парой», `tavern-clothes`).

⭐ С 07.10 (вечер) поведение сектанта по сценарию (появление, шаги, действия,
уход, реакции) проектируется в скиле `tavern-life` — `LIFE.md`; здесь остаются
тело, одежда, клипы и то, что уже в игре (§9–13).

## Как начинать сессию по сектанту

1. `tavern-game/SKILL.md` → `start.py` (мост, play) → `tavern-monsters/SKILL.md`
   → этот файл → `SECTANT.md`.
2. Брифинг по граблям: `python3 ~/.claude/skills/tavern-regress/probes/bugs.py
   персонаж`, `… блендер`, `… монстры`; для клипов — `… анимация`. После
   правки — `check_all.py`.
3. Работа в Blender — ещё `tavern-game/BLENDER.md` (мост, «правки смотрим в
   открытом окне», ⚠️ второе окно на порту 9876 читает чужую сцену — P264) и
   `tavern-game/CHARACTER.md`, разделы «Принципы работы с моделью персонажа» и
   «Модель персонажа».
4. Правка одежды сектанта — `tavern-clothes/BLENDER.md` (функции
   `human_skin_cut.py`) и `tavern-clothes/PITFALLS.md`.
5. Шаг «в игру» — `tavern-monsters/MONSTERS.md` §1–9 (модуль `Cozy.Creatures`,
   спавн, менталка, штурм, дебаг) и `tavern-game/ATTRIBUTES.md`.
