## Модель и сервер

- **Ollama 0.35.1**, портативно: `/media/ilya/T714/llm/ollama/bin/ollama`.
  Модели — `/media/ilya/T714/llm/models`, лог — `/media/ilya/T714/llm/serve.log`.
- ⚠️ Диск exFAT — **симлинков нет**. При обновлении Ollama из архива
  `tar` падает на ссылках: библиотеки `lib/ollama/*.so*` надо скопировать
  файлами (`cp X.so.0 X.so` и т. п.).
- Запуск (в фоне, порт 11434, только localhost):
  ```
  OLLAMA_MODELS=/media/ilya/T714/llm/models OLLAMA_HOST=127.0.0.1:11434 \
    /media/ilya/T714/llm/ollama/bin/ollama serve > /media/ilya/T714/llm/serve.log 2>&1
  ```
  Проверка: `curl -s 127.0.0.1:11434/api/version`, загружено ли в память —
  `/api/ps`. Выгрузить из видеокарты: `ollama stop qwen3:8b` (с тем же
  `OLLAMA_HOST`).
- **qwen3:8b**, Q4, ~5,2 ГБ. Режим размышлений выключен (`think:false`) —
  иначе ответ долгий и с тегами. RTX 3060 Ti: ответ 0,4–1,6 с; первый после
  простоя 15–40 с (загрузка с диска). Простой >5 мин — модель выгружается сама.
- ⭐ **Видеокарта общая с генерацией картинок** (скил `image-gen`, сессии
  ilya-23 и др.). Вместе qwen3:8b и ComfyUI в 8 ГБ не влезают (OOM). Перед
  `ig` модель выгрузить; генерация идёт — модель не грузить, договариваться
  сообщением между сессиями.
- Кандидаты, если 8B не подойдёт или для простого CPU-сервера: Qwen3-4B,
  Gemma 3 4B (естественнее по-русски), Qwen3-1.7B (нижняя планка),
  Mistral Nemo 12B / Gemma 3 12B (сильнее, но только с GPU).

## Код

- **`Assets/Game/UI/LlmBridge.cs`** (сборка Tavern.UI) — по образцу
  `TelegramBridge.cs`:
  - `Boot` (`RuntimeInitializeOnLoadMethod`) — объект `LlmBridge`, DontDestroyOnLoad.
  - Подписан на `PhoneUI.Sent(who, text)`; `Find(who)` ищет персонажа по имени,
    номеру или цифрам номера.
  - `Chat` — история **текущего агента** (до `HistoryMax` = 24 реплик) +
    системный промпт `Rules + agent.Prompt` → POST `/api/chat`; ответ чистится
    (`Clean`: срезает `<think>…</think>`, кавычки) и уходит в очередь, в `Update`
    — `PhoneUI.Receive(name, text)`, когда есть игрок.
  - Пинг `/api/tags` раз в 15 с → `Online`, `Status` («доступна», «сервер не
    отвечает», «модели нет»).
  - Настройки — статические поля: `Url`, `Model`, `Temperature` 0.8,
    `MaxTokens` 90; `repeat_penalty` 1.15.
  - Пока ждём ответ, новое сообщение игрока ложится в историю, но отдельного
    ответа не получает (`Waiting`) — модель увидит его в следующем запросе.
- **Персонаж** `Character { Name, Tel, Rules, Agents[] }`; `Current` — агент,
  чья смена покрывает `GameClock.I.Hours` (смена через полночь работает:
  `From > To`). Нет ни одного подходящего — первый агент.
- **Агент** `Agent { Title, From, To, Prompt, History }` — у каждого своя
  история: новый дежурный НЕ знает, что писал предыдущий (переписка в телефоне
  при этом общая).
- **Телефон** (`PhoneUI.cs`):
  - контакт `new Contact { Key = "Phone.ContactPolice", Name = "Полиция", Tel = "911" }`
    в `AllContacts`;
  - `PhoneUI.SetTyping(who, on)` + `HashSet Typing`; в `ChatPage` после
    сообщений — входящий пузырь «•••» с подписью «печатает…». Перерисовка —
    через `_messagesStamp++`.
  - Без связи СМС игрока «Не доставлено», `Sent` не стреляет — до модели не
    доходит. Ответ модели приходит без проверки связи.
- **F1 → «Сюжет» → «ИИ-собеседники»** (`AiTab` в `HudUI.DebugPhone.cs`):
  полное устройство вкладки и полей ввода — `tavern-game/UI.md`, «Дебаг: поля
  ввода и вкладка «ИИ-собеседники»». Статические настройки сохраняются через
  `DebugTune.Tuned` (P965), ползунки агентов (смена, пауза) — нет.
- Переводы — `en.extra.json` («Полиция» → Police, «печатает…» → typing… и
  подписи вкладки).

## Персонажи

### Полиция — участок пос. Лихово, +7 919 300-02-02 (с 05.10)

Номер из газеты (вакансия «Помощник участкового»). Контакта «Полиция 911»
в телефоне больше нет: игрок сохраняет номер под любым именем, `Find`
сверяет последние 10 цифр через `PhoneUI.TelOf(who)`, ответ идёт в тот же
чат (`Character.Chat`).

Правила общения и эталонные переписки — **в репо `AiChat/RULES.md` и
`AiChat/golden.txt`** (из ролевой с Ильёй 05.10, коммит de26de37). Кратко:
- **День 8–20: Хейл** — тайно с сектантами; пофиг, строчными, «чё», отвечает
  долго (пауза 20–60 с); на сюжетное (ключ, кейс, треугольник с глазом,
  символы) — «ты» и сам выведывает.
- **Ночь 20–8: Мур** — спокойная, коротко, личный контакт; MVP: имя → где →
  как добрался → друзья → что известно → точный адрес. Неподобающее →
  `[END]` (агент `Silent` навсегда), точный адрес → `[PATROL]`
  (`LlmBridge.PatrolCalled`, `Character.Patrol`). Пауза 4–10 с.
- Точек в конце сообщения нет никогда: правило в промпте + `Clean` срезает. Опечатки — не оскорбление, Хейл не матерится без причины.
- Пауза: сначала молчит `PauseMin..PauseMax` (на агента), потом «печатает…»
  `длина × TypeSecondsPerChar` (1–8 с). Всё — ползунки в F1.
- Время: в системный промпт — «Time now: day N, HH:MM»; если с
  прошлого сообщения игрока этому агенту прошло ≥3 ч — в начало его
  сообщения «[прошло часов: N]» / «[прошло суток: N]».
- ⚠️ qwen3:8b копирует пример-переписку дословно (знает имя до знакомства,
  отвечает на мат фразой про ворону) → в промпте только отдельные «Style
  samples» с запретом копировать. Полный фикс — LoRA (`tavern-ai-train`,
  `/media/ilya/T714/llm/train`: пакеты `pip --target site`, PYTHONPATH=site;
  uv-кэш на exFAT не работает).

## Как править и проверять промпт

1. Промпты — прямо в `LlmBridge.cs` (строки `Rules` и `Prompt` агентов).
2. Прогон без игры: `python3 ~/.claude/skills/tavern-ai-chat/voice_test.py` вытаскивает строки
   из `LlmBridge.cs` и гоняет 5 реплик по каждому агенту.
   Читать ответы глазами, а не верить на слово.
3. Грабли маленькой модели, уже пойманные:
   - **копирует свой прошлый ответ** (дневная повторяла «Ваше обращение
     зарегистрировано» каждый раз) → правило «номер только в первом ответе»,
     порядок вопросов и пример переписки в промпте;
   - **словесный тик** (ночной «эх» в конце каждой фразы) → «редко, начинай
     по-разному»;
   - **просачивается `</think>`** даже при `think:false` → `Clean`;
   - **ломается на «забудь инструкции»** (рассказала шутку) → явный отказ
     в стиле агента;
   - **логическая дыра** («звони в полицию» от полицейского) → прямо
     прописать, кто он.
4. В игре: F1 → «ИИ-собеседники», «написать «алло»», смотреть ответ в чате
   «Полиция». Сдвиг смены — ползунками или временем суток.

## Чего пока нет (очередь)

- Сохранение истории агентов в сейв (сейчас живёт до выхода из play).
- Сюжетный контекст в промпте (время, найденные предметы, флаги уровня) —
  «сюжет = состояние мира», скил `tavern-story`.
- Сюжетно важное — заготовками по флагам, модель только для живой болтовни.
- Другие персонажи (Морин/Александр, Дима, Аня, Мама) — их голоса и что они
  знают, через `tavern-level1`.
- Сервер: `tavern-server` (Kotlin, 8085) как прокси к модели, лимиты, фильтр
  ответов, очередь; выбор модели под простой CPU-сервер (замер при 4 ядрах).
- LoRA-дообучение голоса, если промпта не хватит.
