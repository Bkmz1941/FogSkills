# Атрибуты объектов — реестр (единое место)

⭐ Правило Ильи (2026-08-30): «запиши в скил тему про атрибуты — если я вдруг
повторяться начну по функционалу — стопь меня и поправляй». Перед любой
«фичей-флагом» (нельзя кликнуть / нельзя положить / UI по наведению /
кнопка «Осмотреть»…) — сверить с таблицей ниже и с F4 → «Атрибуты» (живой
список из кода). Если просьба совпадает с существующим атрибутом —
**остановить и сказать**: «это уже атрибут X, ставим его объекту Y», а не
писать новый механизм.

Источник истины в коде — `ObjectAttributes.Flags` (`Assets/Modules/Grid/
ObjectAttributes.cs`): имя, описание, предикат по `ObjectDef`. Показывается:
панель атрибутов объекта «Обзор» (`ObjectAttributes.CollectOverview`,
`HudUI.Attributes`), F4 → «Атрибуты» (`UiKitScreenUI.BuildAttributes`: все
флаги и у кого из каталога «да»), вики (O) «виды» (`ObjectSheet.Kinds`,
ilya-1c). Новый атрибут — добавлять СРАЗУ в `Flags` и в эту таблицу.

## Толщина обводки — две ступени, по режиму

`InteractHighlight`: обычный режим — жирная обводка (адаптивная ширина по
габариту, `_width`), режим осмотра — ровно **вдвое** тоньше
(`ThinScale = 0.5`, `SetThin` зовёт `HudUI.Examine`). ⭐ Все ширины ещё раз
поделены на `Thinner = 1.5` (Илья 30.08: «сделай все выделения в полтора раза
тоньше»): максимум 0.027 м, минимум 0.008, коэффициент по габариту 0.03. Третьей ступени нет
(Илья 2026-08-30: «жирность выделения у нас всего 2 — жирная как сейчас и
тоненькая; жирная только в глобальном режиме, в осмотре всё тоненькое»).


**Тёмный кант снаружи (02.09).** Белая линия обводки не читалась на светлых
стенах и у ламп (Илья: «если свет рядом, её вообще не видно»). У каждой полосы
обводки два материала: тёмный `_RimPx = 1` (сдвиг в пикселях экрана поверх
мирового `_Width`, очередь 4001) и белый (4002); кант всегда 1 px на любой
дистанции, копий и полос не прибавилось. Внутренняя сторона линии остаётся
белой: сдвигом копий силуэт внутрь не сжать. Обводки частей получают кант тем же
путём (`InteractHighlight.PairMaterials`). С 02.09 (Илья: «включать только если
объект рядом со светом») кант ставится при включении обводки, если габарит
объекта в радиусе включённой лампы или объект на улице под солнцем
(`InteractHighlight.NearLight`, `LightZones.ZoneAt`); иначе только белая линия.
Список ламп кэшируется на 2 с.

## Как добавить новый атрибут (чек-лист)

1. Поле в `ObjectDef` с дефолтом (дефолт — поведение всех старых объектов).
2. Гейт в ОДНОМ месте (постановка — `GridCursor.Support`, клик/выбор —
   `Interactor.Select`, карточка — `HudUI.Interact`, кнопки — фабрики фич).
3. ⭐ ОДНА строка в реестре `ObjectAttributes.Flags` — панель объекта, экран F4
   «Атрибуты» и справочник читают её сами (2026-08-30). Метаданные строки:
   `inOverview` — показывать в панели объекта (порядок строк = порядок в
   реестре, закреплён тестом), `hideWhenFalse` — писать только когда «да»
   (как «Встроенный»), `defaultOn` — умолчание «да» (справочник показывает
   только отличие), `hasOn` — правда ОБЪЕКТА, а не дефа («Кликабельный» =
   `io.Clickable`). Отдельно дописывать `CollectOverview` больше не нужно.
4. Выставить флаг объектам из просьбы Ильи; проверить в play пробой.
5. Эта таблица + `DESIGN_LOG.md` (цитата задачи) + доменный файл.
